# 学习日程

把固定课表、可调度课程和可学习时段录入后，自动按截止日期智能排序学习任务，并安排到合适的时间。「学习计划」支持 macOS 与 Android，可通过热点、HTTPS 直连或经 SSH 密钥连接的私人云服务器同步数据。

本仓库及公开发布的安装包不包含任何个人课程、课表、任务、完成记录、备份或配对凭据。首次打开是空白日程。

macOS 14 及以上（Apple Silicon）可使用 macOS 版本；Android 8.0 及以上可使用 Android 版本。

快速了解特色与日常操作：[学习日程 · 快速说明书](学习日程-快速说明书.md)。

## 运行

运行 `./Scripts/build-dmg.sh` 可生成 macOS 安装包 `dist/学习日程-macOS-<短SHA>.dmg` 及同名 `.dmg.sha256` 校验文件；打开 DMG 后把「学习日程」拖入「应用程序」即完成安装。`./Scripts/build-app.sh` 是内部辅助脚本，只生成开发构建 `dist/学习日程.app`，不单独交付，也不提供 `.app` 下载链接或路径。需要含 Android APK 的完整发布包时运行 `./Scripts/release.sh`，脚本会生成 macOS DMG、Android APK、安装说明、SHA-256 校验和及可直接转发的 ZIP。首次打开为空白数据库，可以直接添加课程，或点击「载入示例，体验自动排程」。示例一旦通过正式应用的按钮载入，也会保存在本机。

开发环境需要 Xcode 26 或以上（含 macOS 26 SDK）及 Swift 6，应用仍支持 macOS 14 及以上；CI 使用标准 `macos-15-intel` runner 并固定选择 Xcode 26.3，保留完整 Swift、Java、Android 与跨语言测试。该选择避免 `macos-15` 所指向 ARM 资源池的调度容量故障；CI 的 Intel 测试不代替 Apple Silicon 安装包的实际验收：

```sh
./Scripts/test.sh
./Scripts/build-dmg.sh
```

也可在 Xcode 中打开 `Package.swift`，选择 StudyPlanner 运行。`build-app.sh` 与 `build-dmg.sh` 默认 Release；传入 `debug` 可构建调试版。本机构建使用临时 ad-hoc 签名，尚未制作 Developer ID 公证的对外发行版本。

macOS 的「学习日程 → 关于学习日程」显示当前运行应用的版本、构建号、源码标识、构建时间（UTC）和配置。源码标识来自打包时写入的 Git 提交；有未提交修改时附加 `-modified-<源码指纹前12位>`，DMG 文件名也使用该标识，避免覆盖同一提交的干净构建。若打包过程中源码或提交发生变化，构建会停止，待编辑完成后重新运行即可。直接从 Xcode / SwiftPM 运行、或旧包缺少这些信息时显示「未记录」，不会把当前仓库的版本误当成已安装版本。

排查版本时也可运行已安装应用的可执行文件并传入 `--version`：它只打印版本、完整提交、源码指纹和构建信息，不打开窗口、数据库或同步。打包标识回归检查：`python3 Scripts/test-build-metadata.py`；显示逻辑检查：`./Scripts/test.sh --filter AppBuildInfoTests`。

隔离预览：运行 `.build/debug/StudyPlanner --demo`，所有示例操作仅使用内存数据库。不会改动正式数据库。

两端构建版本统一从 `Scripts/version.env` 读取，目前为 1.6.3（构建号 18）。本轮继续保留可选私人云同步：两端上传包含操作时间和删除标记的完整 gzip 数据包，服务器逐条合并并保留最近十版。默认关闭，无需提供服务器信息即可构建；原热点同步继续保留。对应入口与验收边界见 [Android 功能对照](Android/FEATURE_PARITY.md) 和 [云同步部署说明](Server/README.md)。本地包为 `dist/学习日程-macOS-<短SHA>.dmg` 及同名 `.dmg.sha256`、`dist/学习日程-安卓版.apk`、`dist/学习日程-云同步服务端.tar.gz`；Android 沿用已有本地签名。

云同步设置本轮改为两张可选卡片：「HTTPS 直连」与「SSH 密钥」，两种方式分别保存配置，选择卡片后点击保存才切换使用方式。HTTPS 直连仍只接受可信证书的 HTTPS 根地址；SSH 方式填写服务器地址、SSH 端口（默认 22）、登录用户名、导入私钥（可填私钥口令）、SHA256 服务器指纹和服务访问码，连接后在服务器内部固定访问 `127.0.0.1:18090`，无需 Tailscale，也不要求公网开放 18090 或准备域名。首次读取的指纹需与服务器主人核对后保存，指纹变化时停止连接。私钥与口令只保存在本机安全存储，不进入日程同步、备份或安装包；SSH 连接只在同步时建立，结束即关闭，Mac 使用系统 OpenSSH，Android 使用内置 SSH 库。两种连接方式与现有 HTTPS 部署路径见 [云同步部署说明](Server/README.md)。macOS 同步结束或连接失败后，SSH 子进程清理采用有限时等待，超时会强制结束，避免一直显示后台同步。

本轮 macOS 端云同步触发收紧：打开主窗口和回到前台不再触发云同步，保留修改保存、联网恢复与运行期间每小时检查。热点局域网同步的启动/回到前台检查不受影响；Android 端云同步触发时机不变。

## 开发与本地验收

每一轮改动（一个明确的修改目标，或一轮用户反馈，而不是每次保存文件）都作为独立 Git 提交推送到已有 `origin`，提交前检查 diff、只显式添加本轮文件，不提交个人数据、密钥、日志和构建产物；推送失败时保留本地提交并如实报告，不强制推送，也不覆盖既有工作。完整的开发流程、DSH 委派规则与发布边界见 [AGENTS.md](AGENTS.md)。

已有命令：

```sh
# macOS：单元测试与安装包
./Scripts/test.sh
./Scripts/build-dmg.sh          # 生成 dist/学习日程-macOS-<短SHA>.dmg 及同名 .dmg.sha256

# Android：单元测试与 APK 打包
./Android/test.sh
./Android/build.sh              # 生成 dist/学习日程-安卓版.apk

# 与 GitHub Actions 相同的完整验证（Swift、Java、Android、跨语言数据往返）
bash Scripts/test-ci.sh
```

两端共用的网站抓取脚本只维护 `Sources/StudyPlanner/Resources/` 中的一份源文件。Android 测试和打包通过 `Android/prepare-assets.py` 生成被 Git 忽略的 `Android/build/assets/`，并把学丞状态判断依赖分别打入目录、回放入口；不要在 `Android/assets/crawlers/` 中另存共享脚本副本，该目录只保留 Android 专用脚本。可先运行 `node Android/tests/crawlers.test.js` 快速检查实际打包脚本及其独立注入行为，再运行完整 CI；打包后也可传入解压出的 `assets` 目录复查成品。

macOS 安装：打开 `dist/学习日程-macOS-<短SHA>.dmg`，把「学习日程」拖入 DMG 中的「应用程序」文件夹，再从「应用程序」启动。首次启动若被系统拦截，在 Finder 中右键应用选择「打开」确认。校验安装包：在 `dist` 目录执行 `shasum -a 256 -c 学习日程-macOS-<短SHA>.dmg.sha256`，输出 `OK` 表示文件完整。

代码改动推送后按影响范围打包，本地验收从打包产物进行，而不是直接从源码目录运行；能自动验证的自动验证，需要人工交互的部分给出具体步骤并说明尚未验证的部分。macOS 受影响的每一轮代码改动仅交付可拖到「应用程序」安装的 DMG 及同名 SHA-256 校验文件，不单独交付 `.app`；Android 仍按影响范围生成 APK。发现问题修复后进入下一轮独立提交。仅文档修改无需重新打包。默认不创建公开 GitHub Release，不上传安装包，也不做部署。

## 已实现

- 学习课程新增、编辑、删除（同时清除全部安排和完成记录）；总量、导入进度、截止日、开始日、优先级、颜色、备注、可选发布时间、自动排程开关。
- Mac 学习监督：在课程编辑中选择对应的观看软件，绑定仅保存在此 Mac，不同步到 Android 或云端。监督只检查对应软件已打开且正在播放，不核对具体课程、网站或课节。详情见下文。
- 固定事项支持「固定时间」与「时段内浮动」：指定窗口和连续占用分钟数，只预留实际时长。窗口内的学习任务使用虚线卡片、双向箭头和「时段内完成」标签；浮动事项另有占用比例条。两端均保留浮动字段并参与同步，旧数据继续按固定时间读取。
- 固定事项、每周多个星期重复、单次考试或会议、学期起止日期与持续周数；检测固定事项之间及正在进行的任务冲突。
- Mac 单项与批量学习确认在保存期间显示进度，暂停修改分钟数、学习日期及关闭窗口；保存失败后恢复操作并保留输入。
- 两端批量确认可刷新待确认列表，保留仍在列表中的分钟数与学习日期；变化项必须重新核对，已确认或不再待确认的任务退出列表，刷新不保存进度。Android 保留各页原始输入，变化项须重新勾选核对，留空项目不提交。 Android 支持按课程、课节和原计划日期后台筛选，显示筛选外已填写数量；隐藏行的输入错误会自动清除筛选并定位到对应页面。
- Mac 批量确认可按课程、课节和日期组合筛选；批量标记只作用于当前结果，筛选不清除其他选择，界面显示筛选外已勾选数量。可逐项勾选或暂缓，只保存全部已核对项目；成功后继续显示剩余待确认任务，仍在列表中的输入保留，选中项有冲突时整批不写入。
- 两端单项确认可「载入最新安排」并保留输入；任务已确认、移除或所属课程已删除、归档时提示返回核对，不恢复旧任务。暂停自动排程的课程仍可确认已有任务。
- Mac 固定课表的当前和已完成事项都可「复制」为独立的新事项：保留名称、时段、星期、浮动占用和备注，清空旧的临时跳过日期；从日历所选日期（不早于今天）开始，重复事项保留原持续天数并限制在未来十年以内。先在编辑窗口核对，再保存并检查冲突；原事项保留。
- Mac 固定事项编辑窗口在保存或删除期间显示进度并暂停编辑、重复提交和关闭；冲突处理对应点击保存时提交的内容，失败后恢复编辑并保留输入。
- Mac 课程列表可按名称、备注和截止日期（YYYY-MM-DD）组合搜索，并筛选自动排程或已暂停课程；后台检索按截止日期排序，显示匹配数量和清除入口。切换页面保留筛选，课程同步变化后刷新结果；筛选不改变课程和课表。
- Mac「固定课表」将已结束事项默认收进「已完成」折叠区，可展开查看及删除。周期事项在最后一次课结束后归入其中，浮动事项按整个窗口结束时间判断；临时跳过不会提前结束课表。删除会完整移除所选事项规则及其过去、未来课表并重新排程，已完成事项也可删除。
- Mac「固定课表」支持名称关键词与星期联合筛选；单次事项按发生日期、周期事项按原定星期匹配，临时跳过仍可查到。已完成事项有匹配结果时可展开查看。顶部文字导入默认折叠，收起后保留本次输入与识别结果；展开后可粘贴通知或聊天文字，在本机提取事项名称、日期、时间与常见重复规则，再点击「核对并添加」进入编辑器保存。相对日期按点击识别当天换算（如“明天晚上18:00”），候选显示依据的日期；跨天或切换 Mac 时区后须重新识别，保留原文。届别不作为年份。缺少结束时间时暂按一小时预填并提示，重复事项缺少截止日时暂按16周预填并提示；时间不明确、冲突或跨午夜内容需核对。支持分行识别多条日程，每次最多30000字、20条候选，原文保留在备注中，文字不上传。
- Mac 与 Android 日历的「复制当天安排」将所选日期整理为文字，包含时区、课程与课时、固定事项、浮动完成窗口、完成状态和本日临时移除事项。完成记录按原计划日期列出，不作为当天实际已学合计；备注与来源链接不附带，复制不修改日程。
- Mac 与 Android 的「周学习统计」支持上一周、本周、下一周和复制周统计摘要，统计周与日历所选日期保持一致。摘要列出每日及各课程的实际已学和课表计划，同名课程分开列出；日期不明的旧记录单独提示，备注和来源信息不附带。Mac 图表可切换课表计划与实际已学，实际已学包含已归档或已删除课程的历史记录。切换视图、周次和复制均不修改日程或进度。
- 两端日历均可「跳到日期」，直接选择年、月、日查看历史或未来安排；确认后同时更新所选日期与月历，取消保留原位置。
- 两端固定事项可「查看日历」，直接定位今天或下一次规则日期；已结束事项定位最后一次。临时跳过的日期仍可查看并恢复，单次事项只显示实际发生日期。
- 在主页日历选中今天或未来某日，点击对应固定事项占位卡片的「仅此日移除并重排」，即可释放这一天的占用并重排今天及未来未确认课程；今天已经开始的事项也可临时取消。其他日期的重复规则、往日记录和已确认进度保留。「本日已临时移除」提供恢复入口，恢复前检查固定事项冲突。固定时间、浮动事项和单次事项均支持，移除日期随数据保存与同步。
- 冲突详情按日期列出事项名称、起止时间、重叠时段和分钟数；浮动容量不足会解释原因；未确认的学习任务允许自动移动。每个冲突日期可独立选择「跳过新课程（不植入）」或「跳过本地固定事项」，也可按同一种方式全部跳过并保存。同一天的多个冲突统一处理；跳过本地时，仅临时移除当天冲突的本地固定事项，可在主页恢复，其他日期、无关事项与历史记录保留。未确认的冲突仍阻止保存，保存失败不会留下部分跳过的结果。
- 每周每天多个可学习时段；休息日、全局与课程级自定义最小时间块。
- 独立月历、当天时间轴、课程进度与每日建议。Mac 主页左侧的起止时间默认放大为 17 / 15 号字；在「学习设置 → 显示设置 → 主页时间字号」可在 14–24 号之间调整，改动立即生效并自动保存，也可一键恢复默认字号。
- Mac 主页区分「待学计划」与「实际已学」：实际已学沿用日报的实际学习日期口径，补录不会计入录入日；同日确认的旧记录标明来源，跨日不明确的旧记录提示待核对并保留课程总进度，合计溢出明确提示。当天汇总及单节时长使用小时和分钟。右栏将继续学习入口、实时预警和课程进度放在周图与后果预报前；「周计划时长」标明日期范围及包含已确认任务原计划的口径，图例换行显示全部课程名。
- Mac 与 Android 日程搜索支持「接下来 / 历史 / 全部」：默认显示今天及以后未确认的安排，包含跨午夜仍落在今天的任务；历史包含已确认记录与往日安排，按最近日期优先，全部按日期从早到晚排列。可用空格组合课程、课节和日期关键词（例如 `高数 2026-11-04`），兼容全角输入；Mac 日期按当前本地时区，Android 按北京时间。筛选仅改变查看范围，不修改日程。
- Mac 主页今天及未来日期的未确认课程板块支持长按约半秒后拖动：拖到另一课程或同一套课的另一课节板块上松开，交换本日两块的位置；目标高亮并显示「松开交换」，落在空白处取消。保留课程时长、固定事项及课间休息，仅调整选中日期，松开后立即播放交换动画并在后台保存；最终写入重新核对当天任务和顺序，相同交换已同步时不重复反转，发生冲突则恢复数据库中的最新安排，跨天不交换往日任务；退出应用会等待本次保存完成。顺序保存后重开仍沿用。当天空间不足时保留原安排并提示；后续更改学习量或可用时段导致顺序不可行时，自动排程优先保证时间约束。拖动以低优先级手势挂载，课程块上的「确认完成」与「部分完成/未完成」按钮点击照常响应，只有按住约半秒才进入拖动。
- macOS 主页右栏顶部的「立即上某节课」使用原生两层菜单：一级列出已启用自动排课且有未完成课节的「分节研习」课程，二级列出该课程任意未完成分节并显示「剩余 X 分钟」。选中任意一节即从当前时间向上取整到分钟开始安排，并把该课节作为新的排课约束：当前空档放不下整节时，先开始当前能放下的一段，该节总剩余分钟不减少；后续排程优先接续同一节（先于同课程其他未完成课节），今日时间不足时，可将原有未确认课程移出今日，按各自截止日期重排到后续可用时段与日期；这只替换原计划，不删除课程或减少未完成学习量。今天已过期但未确认的旧计划不视为已学习，也不强制休息；已确认的学习记录保留，日期、可学习时段、固定事项与真实学习后的 15 分钟休息仍然保留。立即学习高于混排、每日加量、课程优先级、均衡与拖动顺序。若后续学习量无法全部排入，保留未完成量并在正常课表预警中提示，不因旧课表的已排入量发生变化而撤销立即学习。真正无法开始时才报错并保留原数据。选择课节视为一次正式重排，结果保存到日程；不再提供「取消立即学习安排」按钮或撤销该安排的功能。分段课节在首段结束或确认后继续优先接续，直到整节完成或再次选择其他课节重排；普通整节的开始时间在结束或确认前保留，修改硬性时间约束使其失效时让步重排。仅 Mac 提供入口，Android 未新增。

- Mac 主页预警按实际课表区分「已安排、仍可按期」「能排但学习负担偏重」「当前方案还没排好」「已确认存在时间约束冲突」。未排入量不会直接当作真实时间缺口；只有乐观时间上界仍不足或整块内容大于最长连续空档时才确认冲突。部分完成后仅按实际确认分钟扣减，并展示已排入的待补内容分布在哪几天、各日纯学习量与最重一天。学习设置可调整每日负担提醒线（默认 8 小时，本机保存），不会改变可学习时段或截止日。Mac 提前全量确认及仅同步刷新时，预警、待补安排与每日学习量按实际保存的课表核算，不使用尚未应用的新排法；已有未排入内容不会因仅刷新预警而消失。
- Mac 自动排程优先守住截止日期，混排和倍率在需要时让步；不允许后续混排丢失更早截止日前已经排入的学习量。遇到未排入时，对支持范围内的课表联合搜索浮动事项窗口内位置与整节课顺序，搜索有预算上限；未找到完整方案如实显示待优化，不当作无解证明。两种调整都会显示原因。按整节排程时，不再把缩小普通课程的最小时间块作为通用补救。
- Mac 与 Android 的联合救援支持同一天多个浮动事项，也支持不足 15 分钟的短事项。课节与事项可一起换位置，短事项可以占用部分课间休息，两节学习间仍须间隔至少 15 分钟；只采用全部剩余课节与事项均能放回的完整方案。偏好评分与已保存顺序保持原规则，设置页明确说明混排口径及默认三倍加量例外。范围、对照案例与验收边界见 [联合浮动排程改进](Experiments/Scheduling/joint-floating-results.md)。
- macOS 与 Android 的「学习设置」新增「排课逻辑权重」面板，列出已有排课原则。日期、固定课表等时间约束固定为 0 级、必须遵守；多科混排、每日加量、课程优先级、学习量均衡四个已有偏好可设为 1–4 级，数字越小越优先，同级沿用默认顺序，默认依次为 1、2、3、4。可恢复默认，点「保存并重排」生效，设置随日程保存与同步。
- 自动排程先生成满足时间约束的可行课表，再以完整课表为单位按保存的规则顺序逐级比较：低级偏好不能抵消高级偏好的损失，同级按默认顺序。局部优化会尝试跨日移动、满日换课和当天交替，保留每门课程已排入的学习量、整节顺序和至少 15 分钟课间休息；搜索有确定性预算，不保证全局最优。单节移动、两节交换之后，两端还会联合重排连续最多 4 天中的 3–12 节课（至多 4 科），区域外课节在本次尝试中保持原开始时间，只接受整份课表按原规则严格改善的完整方案；超过预算保留已找到的最好方案，未完成的候选不采用。实现与对照结果见 [本地联合优化](Experiments/Scheduling/local-repair-results.md)。长短课节差异较大且多天混排不足时，会尝试同时保留多种课程队列前缀，用截止容量与整节最晚开课时间排除来不及完成的组合；只接受保留每门已排入学习量的完整方案，否则保留现有方案。该队列搜索范围最多 6 门课程、600 个待排块、366 天与 1500 个学习窗口，每个方向最多 60000 次扩展；超出范围或预算保留当前方案，不能当作无解证明。
- 「学习设置 → 排课原因」中的「当前为什么这样排课」按已保存设置和最近一次排程解释实际回退、较早截止课程与每日加量；修改权重后需保存并重排才更新说明。初始混排若会丢失原方案已排入的学习量，会整份退回截止日期优先的可行方案，并在回退结果上继续做局部优化；因此仍可能连续集中安排某门课，不能据此认定只有这一种可行排法。
- macOS 课程页最上方新增可折叠的「极限压缩方案」卡片：在独立后台任务中搜索所有未完成课程全部学完的最早时间，目标是最小化这些课程的最晚完成时间，计算不阻塞前台操作，完成即停止；计算完成后保留本次基准方案并休眠，始终标注计算日期；跨天、日常确认（含未完成、部分完成和撤销）、普通任务重排、标题备注及原截止日期修改均不重算。仅课程/课节增删、时长或顺序变化、未来固定事项的占用变化、每日学习时段或实际使用的最小学习块变化触发自动重算；每次都从当时日期与最新剩余量生成新的基准。旁边的「重新计算」按钮可随时手动刷新。完整结果缓存在本机，退出重开继续保留；旧版首次升级或缓存不可读时重新计算一次。方案把固定事项与每日学习时段当作时间约束，不额外保留课间休息，不受原开始日、截止日、每日加量、自动排程开关（含已暂停的未完成课程）限制；课节不可拆分并保留原有顺序，没有课节的课程沿用既有最小学习块。完整搜索结合容量下界、动态规划状态支配剪枝与完成时间二分来验证方案最优；未来十年内无法排完或学习时段、固定课表设置无效时给出原因提示。展开后可查看每门课的最晚完成时间和只读的日历、当天课表预览，预览只用于对照，不应用到正式日程。Mac 会保存有大小上限的展示结果，通过已有云同步供 Android 只读查看；Android 不包含压缩算法或参数，课程、进度、时段或日期变化后标记旧结果待更新。

- SwiftData 本地持久化、保存失败回滚、启动失败时明确报错且不覆盖已有数据。
- 通过手机热点按需双向同步；首次配对由 Mac 生成一次性二维码、Android 扫描，不需要复制配对串。
- 可选私人云同步（默认关闭）：设置页以「HTTPS 直连」「SSH 密钥」两张卡片切换连接方式，两套配置分别保存、互不覆盖。HTTPS 直连保留可信证书验证，只接受 HTTPS 根地址。SSH 密钥方式填写服务器地址、SSH 端口（默认 22）、登录用户名、导入私钥与可选私钥口令、SHA256 服务器指纹和服务访问码；隧道内固定访问服务器本机 `127.0.0.1:18090`，不需要 Tailscale、公网开放 18090 或域名。首次读取的指纹必须与服务器主人核对后再保存，之后指纹变化即停止连接。服务访问码仍按 `Authorization: Bearer <SERVICE_ACCESS_CODE>` 使用，与 SSH 密钥无关。私钥和口令只保存在本机安全存储，不进入日程同步包、备份或安装包。SSH 连接只在同步时建立，结束或失败后关闭；Mac 使用系统 OpenSSH，Android 使用内置 SSH 库。
- Mac 同步期间顶部显示「正在后台同步，可继续修改」与原生旋转加载动画；数据刷新和学习负荷计算在后台进行，完成或失败后结束提示。
- macOS 同步在后台进行，期间可继续编辑课程、课表、确认学习与调换日程；修改先保存本机，再合并并补传。
- Mac 课程编辑以打开窗口时的数据为基准：名称、备注、颜色与其他未冲突的新数据可以合并；同一字段或排程数据发生冲突时会提示重新打开。已被同步删除的课程不会因旧窗口保存而恢复。网站后台更新保留当前选择的「自主研习 / 分节研习」方式。

没有 EventKit 或系统日历事件。热点按需同步见 [同步使用与实现报告](同步说明.md)，可选私人云同步（HTTPS 直连或经 SSH 密钥的隧道）及 Linux 部署包见 [云同步部署说明](Server/README.md)。代码里的 `Foundation.Calendar` 仅用于日期和星期运算，与 macOS Calendar 应用无关。

## 使用流程

1. 在「学习设置」录入每天可学习时段并保存。
2. 在「固定课表」添加学校课、补习班及休息时间。重复日期按本地星期计算；开始日和结束日均包含在内。
3. 在「课程管理」录入总小时数、已完成基础量和截止日期。基础量与应用内已确认的进度相加。macOS 也可以从课程网站抓取课节（见「从课程网站导入课程」）。按节课程创建后，可在课程卡片点击「调整课节顺序」批量移动课节并重新排程。

   macOS 的添加与编辑课程改为「设置总览」加分项详情：课程信息、学习内容、排程规则、学习监督。可从总览直接进入任意一项填写，返回与前进都会保留本次尚未保存的输入；核对后在「确认课程」页点「添加课程」或「保存更改」，点「取消」则不保存。学习内容中可打开网站/网盘导入；关闭导入窗口后当前课程草稿保留，导入窗口自己的「导入并生成计划」会单独保存来源课程。

   上课方式只有两种：「自主研习」只需填写总学习时长，系统按时间块分配；「分节研习」录入或导入各节名称和时长，按课节安排。旧的录播课程、补习回放与其他学习统一显示为「自主研习」，原有进度与排程保留。

4. 在日历查看安排。圆圈按钮确认全部完成；省略号可填写实际完成分钟数。未来日期同样支持操作。
5. 晚间确认时间之后，或第二天首次打开时，确认未完成计划。每项都需要明确选择，避免默认把未勾选项目算作漏学。
6. Mac 出现预警时，先点「查看补回安排与每日负担」：区分学习负担偏重、尚未找到完整排法和已确认的约束冲突，再核对具体时段与课节；未排入量不等于真实时间缺口。

补确认已结束的任务（包括批量全部完成）会重新排程，扣减未来重复安排的学习量；撤销确认也会重新排程，恢复尚需完成的学习量。浮动任务以整个完成窗口结束为准。「载入示例」仅在没有课程、固定事项、任务和完成记录时可用。

应用退出时不在后台补做跨天确认；下次打开时补查并重排。跨天检查每 30 秒进行，重新激活窗口时也检查。

## 从课程网站导入课程（macOS / Android）

在 Mac 的「添加/编辑课程 → 学习内容 → 从网站导入课程」打开导入窗口，同时跳转系统默认浏览器。顶部地址栏可输入 HTTPS 网址（省略协议会自动补全），回车或点「在默认浏览器打开」跳转；「恢复默认地址」打开研途「我的课程」。登录后在浏览器选中课程标签页，再回到学习日程点「读取浏览器当前课程」。课程汇总、课节预览、选择及「导入并生成计划」保留在应用内。Android 继续使用原有内置网页流程。

Mac 支持 Safari 及提供 Apple 事件 JavaScript 接口的 Chrome 系浏览器。首次读取需允许「学习日程」的系统自动化权限，并开启浏览器的「允许来自 Apple 事件的 JavaScript」：Safari 在网页开发者设置中开启，Chrome 通常在「查看 → 开发者」菜单中开启。设置位置参考 [Apple 开发者说明](https://developer.apple.com/documentation/safari-developer-tools/developer-settings) 与 [Chromium 说明](https://www.chromium.org/developers/applescript/)。不支持此接口的默认浏览器仍能打开网址，但会明确提示无法读取课程。

读取只连接用户选中的、与地址栏网站一致的标签页。切换浏览器的活动标签页不会把读取目标换到其他页面；原标签页完全刷新、关闭或移动导致连接失效时，需要重新选中课程页并点击读取。已连接页面可每 5 分钟刷新；关闭导入窗口会断开连接、清理页面的本次识别缓存，浏览器本身和登录状态保留。已经发出的网页请求可能继续完成。这里的「每 5 分钟刷新」只在导入窗口打开期间工作，关闭窗口即停止；导入后需要按间隔继续更新，请用课程列表的「网站来源与更新」（见「已实现」），它不依赖导入窗口。

Android 的课程页也提供同名导入入口；网页和抓取结果上下排列，可收起网页，选择课程、截止日期后预览及导入。每次关闭窗口都会清除登录会话。

抓取按站点自动选择模式。

**研途：专用适配器。** Mac 在浏览器进入「我的课程」后点「读取浏览器当前课程」抓取；Android 进入后自动抓取，也可以点「重新抓取全部课程」。两端均可勾选「每 5 分钟刷新」（仅导入窗口打开期间生效）。抓取的是当前登录账号下的正式课与体验课，包含已隐藏的课程包；已失效的课程包只列出名称和原因，不读取课节也不能导入。

**其他网站：通用识别。** Mac 点击「读取浏览器当前课程」后开始识别，Android 在内置页面加载时开始识别；记录该页面自己发出的同源 JSON 响应——它不发起任何新请求，也不读取 Cookie、令牌或请求头。Mac 请先连接一次，再在同一浏览器标签页内返回「我的课程」并逐门点开课程目录；连接前已加载的接口数据不能补读，完整刷新网页后需要重新连接。Android 登录后打开「我的课程」，再逐门点开课程目录；每打开一门，程序就在这些响应里用字段启发式还原课程与课节并自动累加到列表，可以连着点开多门，Mac 也可手动点「读取浏览器当前课程」（Android 为「重新识别课程」）。

**学丞教育：逐层读取目录与直播回放。** 打开 `ixuecheng.cn/detail` 后，程序会按顺序遍历各层章节，包括只有箭头的二级目录。网站的分组互斥展开，程序会先等待当前分组加载并保存结果，再读取下一组，不再反复尝试将所有组同时展开。后台识别复用本轮已读取的目录；手动重新读取或每 5 分钟刷新才重新遍历。已发布直播按保存的章节位置打开回放，从嵌入的回放页读取播放器时长或直播起止时间；失败的回放本轮不循环重试。尚未开播的直播保留为未发布条目。Mac 还会读取课节行和回放页的状态文字：明确提示尚未更新、回放生成中或直播尚未开始的条目保留在目录，暂不计入排程时长，后续更新时再次检查；登录、权限、网络错误或没有明确待更新提示的时长读取失败仍需处理，不会直接当作未发布。Mac 在同一浏览器中临时打开回放标签页，等待回放页文档就绪后读取时长，支持在受支持的回放域名 view.csslcloud.net 内跳转和页面重载，完成后关闭该临时标签页；Android 保持原有 WebView 流程。回放链接仅在内存和当前浏览器会话中使用，不写入课程快照；回放页没有提供可验证的观看进度时按 0% 估算。已发布回放若无法读取时长，该课程不能生成计划。

还原规则：识别常见命名（`name`/`title`、`duration`/`videoDuration`/`length`/`seconds`、`percent`/`progress`/`schedule` 等）；时长既接受数字，也接受网站已经格式化好的文本（`45:30`、`01:02:03`、`45分钟`、`1小时20分`）；按「有名称且有时长或进度」判定课节，纯章节节点不会被当成课节；课节若自带课程编号（如 `courseId`），同一门课的多个章节会合并成一门课程，没有课程编号时退回到「最外层列表项」分组。单位按整份响应统一换算（毫秒与秒、0–1 比例与 0–100 百分比），避免把「1%」读成「100%」。课程名按「课节自带的课程名 → 响应根节点名称 → 页面标题 → 域名」的顺序兜底。

学丞的空章节（包括只有空目录容器、没有提示文字的章节）在同源请求结束且页面稳定后正常跳过，继续读取后续章节；整门课程为空时显示暂无可读取课节。仍在请求或加载中的章节会继续等待，请求失败或超时会明确提示原因。

通用识别只认页面已经加载过的数据；学丞教育直播回放使用上面的专用补充读取。其他网站若必须逐节点开才返回时长，就得逐门点开（点开的结果会累积，不会互相覆盖）；网站没给时长的课节不计入总学习量但仍保留在列表里，没给进度的按未观看计入。识别出的课程名、节数与总时长请在窗口内核对后再生成计划。

每个课程包依次读取全部科目（大纲）、阶段、章节和课节，并合并直播课节。研途模式下每个课节记录时长、网站观看进度、是否发布、是否被手动标记完成；直播课节不猜时长和进度。观看比例只来自网站，手动完成标记不会覆盖实际观看比例，也不作为已完成学习量。

导入是整体成功或整体失败：只要有一个课程包抓取不完整（分页数量不一致、某个科目请求失败、已发布课节缺少时长或缺少观看进度、课节编号重复、返回的时长或进度越界），该课程包会被标出原因且不能勾选；存在任何全局问题时，「导入并生成计划」保持禁用。默认勾选所有没有问题的课程包，可自行取消。

生成计划时，总学习量按合计秒数向上取整到分钟；「已完成基础量」按课节核对网站观看量与应用内流水，只扣除同一课节中重叠的进度。网站已记录的基础进度、其他课节的本地完成量和抓取之后的新确认都会保留；重复刷新不会重复累计。没有课节标识的旧流水沿用保守的总量核对。撤销本地确认时仍保留网站已验证的观看量，合并课程也适用。网页课程自动改为按课节排程，一节对应一项任务；默认按照网站返回的科目、章节与课节顺序学习，只有用户在课节顺序编辑器中选择「智能排序」或手动移动时才改用自定义顺序，编辑器也提供「按网站顺序」恢复。再次抓取时，跟随网站顺序的课程会同步网站的新顺序，用户自定义顺序保持不变。剩余时长无法放入连续空档时会显示未排入风险。课程编辑页和导入结果都能查看逐节编排预览。保存按课程包编号匹配已有课程：未归档的已有课程保留开始日、截止日和优先级；重新导入已删除课程按新课程处理，从今天排至所选截止日；原应用内完成记录不会恢复。新课程也使用所选截止日（默认 90 天后，可选当天起十年内）。

Mac 复用默认浏览器已有登录状态，不读取或导出 Cookie、令牌及请求头，不同步浏览器登录信息；Android 内置网页登录会话保持原有行为。研途适配器只调用该站自身的只读 GET 接口；通用识别只旁观已连接页面自己发出的同源 JSON 响应；学丞回放沿用网站的点击入口。地址栏只接受 HTTPS。外部浏览器的导航由浏览器管理，应用只读取指定网站，页面离开该站或连接失效后停止读取并提示重新连接。网页脚本结构变化、目录不完整或已发布回放缺少时长时不会生成猜测的完整结果。Android 操作与验收边界见 Android/FEATURE_PARITY.md。

自动化测试用本地 WebKit 页面驱动真实注入脚本，覆盖分页列表、科目与阶段章节解析、观看进度、未发布课节、重复课节去重，以及单个科目失败时不计为完整课程；地址栏补全、HTTPS 校验与同站点判定另有纯函数测试。通用识别另有 14 个纯函数用例，覆盖嵌套章节归并、按课程编号合并同一门课的章节、多门课程拆分、毫秒换算、格式化时长与百分比文本、单位与比例的整响应一致性、无时长课节不阻塞导入、播放位置换算进度、跨接口去重合并，以及无课程数据时返回空结果。

## 从夸克网盘导入课程（macOS）

在「添加/编辑课程 → 学习内容 → 从夸克网盘导入」粘贴 `https://pan.quark.cn/s/...` 分享链接；链接若指向 `#/list/share/<目录编号>`，会从该子目录开始。页面加载后自动递归读取文件夹和分页，识别视频、按目录与讲次自然排序，在左侧展示课程候选与每节课。提取码分享可在窗口填写提取码；需要登录时可在右侧页面登录后重新读取。读取只访问夸克的分享令牌与目录接口，不转存、下载或修改云盘文件。

识别结果按分享目录折叠成大分类，每个分类可批量勾选或清空。分类小标题和课程名称以更大的加粗字体显示。搜索框支持课程名、目录路径和课节名；搜索后可批量勾选或取消匹配结果，也可点击课程卡片的「定位课程」，清除搜索、展开所属分类并滚动到完整目录中的对应课程，蓝色边框和「已定位」标识便于确认位置。定位保留已有勾选。顶部「全部勾选」「全部不勾选」作用于整份识别结果，其中无法导入的课程不会被勾选。课程卡片显示原目录路径，便于核对名称相近的候选。

勾选至少两门候选课后，可打开「将已选课程合并为一门」，编辑合并后的课程名称并预览课节。合并时先按来源课程，再按章节和课节编号智能排序，原文件路径和来源课程仍保留；导入后在课程卡片中点「调整课节顺序」可手动重排。再次以相同候选课组合导入会更新同一门合并课程，并保留已设置的课节顺序。

课程判定结合视频占比、目录和文件名中的课程词、连续讲次、视频数量及时长。特征较弱的候选不会默认勾选，仍可人工核对。课内同名同讲次的文件按大小、时长、清晰度识别：接近的副本导入时只保留最佳的一份，明显不同的版本全部展示并提示核对；跨文件夹的课程按课节集合与时长、体积比较，只有课节完整一致且信息接近的课程才默认去掉一份。与已有计划高度重合的课程也不会默认勾选。目录未读完时禁止导入，避免形成残缺计划。导入后保存分享来源、原文件路径、时长估算与查重摘要；分享令牌不写入本地课程数据。

命令行可用 `学习日程 --netdisk-probe '<分享链接>'` 只读检查课程识别与查重摘要。夸克网页接口可能变化，届时会明确显示解析或请求错误。

分享目录树分别统计直属文件与子文件夹；视频、讲义等文件不会重复计为文件夹，空文件夹仍保留。课程的视频数量、时长和文档数量继续包含其下所有子目录。

## 排程语义与架构

`Sources/StudyCore` 不依赖 SwiftUI 或 SwiftData。

- `Course` 保存总分钟数与导入进度，`CompletionRecord` 是完成流水。剩余量 = 总量 − 导入进度 − 已确认流水；计划本身不扣减进度。
- `Course.webCourse` 保存最近一次网站抓取快照（课程包编号、各课节时长与观看进度、抓取时间与问题列表）。`Course.manualLessons` 保存手动录入的课节。快照和课节随课程记录同步；Mac 与 Android 均按逐节剩余时长排程。
- 网站抓取输出同一个 `WebCourseSnapshot`：研途走注入页面的 `CourseCrawler.js`（依赖该站前端模块命名，自行分页遍历全部课程包）；其他站点走 `GenericCrawler.js` 嗅探页面自己的同源 JSON 响应，再由纯函数 `GenericCourseDigest` 用字段启发式还原课程与课节。学丞教育课程详情页另外展开直播目录，逐项进入已发布回放，并从回放页读取时长；未取得时长的已发布回放会阻止该课程生成计划。导入流程与全部校验对各通路一致，因此持久化、同步与 Android 端无需区分来源。
- `ScheduledTask` 保存原计划及确认状态。重复确认会被拒绝。未完成不增加额外债务，只保留尚未学完的量。
- `ScheduleEngine.generate(state:now:)` 是纯函数。输入日期、固定课表、可用时段、课程与完成记录，输出未来任务、每日建议和风险诊断。
- Mac 与 Android 的相邻课节或学习块之间至少保留 15 分钟间隔（同一课程也适用），休息不计入学习进度。间隔跨可学习窗口与午夜保留；重新排程也保留已确认或刚结束任务后的休息。最后一节不需要在可用时段内额外预留尾部休息，排不下的学习量显示未排入风险。
- 自动排课在可行时优先安排至少三门不同课程，避免普通优先级或不足三倍的加量让一门课主动占满全天。只有两门可排时尽量混排两门；固定事项较多、可用时段不足、课程数量或课程日期受限时，正常安排能容纳的一两门，不因不足三门报警。当天实际排入三倍课程时允许集中安排。为后续日期保留多样性前会检查整节课和休息能否共同容纳，不为无法混排的日期硬留课节，也不因此搁置当天截止的学习量。仍遵守课程日期、课节顺序、整节时长、固定事项和课间休息；真正未排入的学习量继续显示截止风险。
- 浮动事项先计算一组窗口内互不冲突的连续占用位置，作为容量计算依据；这些位置不会显示为真实预约时间。多个浮动窗口可以重叠，占用时长累计。组合搜索有上限，无法找到安排时提示调整窗口。受影响的学习任务保存完成窗口；窗口开始后仍可从当前时间重新安排，旧的未结束计划会被替换，窗口结束后再进入待确认。
- 所有计算使用整数分钟，区间为左闭右开；截止日期包含当地当天。最后一个不足最小单位的尾块允许缩短，保证不凭空增加学习量。
- 计划已开始不代表实际已学习，未结束且未确认的任务全部参与重排（包括浮动窗口），不再预留或锁定；已结束但尚未确认的历史任务不计入已完成，余量继续进入新计划。之后再确认历史任务，未来负担相应减少。
- 历史和已确认任务不被自动删除。提前完成的记录单独展示，不继续占用未来时间轴。
- 固定课表编辑会拆分历史与未来规则；当天已经开始的那次课也保留。Mac 显式删除固定事项时，会移除所选规则的全部课表，不再只缩短结束日期；单日临时移除仍可恢复。删除课程会同时移除全部安排和完成记录；旧版本通过归档移除的课程会在读取时清理，并通过同步传播删除。
- Mac 删除固定事项会保留点击删除时核对的规则版本；窗口打开后规则若被同步修改，或新版本先到达本地数据库，旧删除会被拒绝，需查看最新规则后重新确认。编辑窗口中尚未保存的输入不作为待删除的已存版本。
- Mac 删除课程会保留确认前核对的课程和学习记录；确认期间新增、修改或移除的学习记录（包括零分钟及无对应任务的旧记录）都会阻止旧删除，数据库事务中再次检查。未保存的表单输入不作为课程版本，普通待学计划的重新安排不影响删除确认。
- Mac 单日移除或恢复固定事项会复核当天名称、时段和占用时长，保留其他日期及备注的更新；数据库事务再次按最新规则执行，恢复时若已新增冲突事项则不保存。另一端已完成同一单日操作时按原结果保留。
- Mac 学习确认、批量确认和撤销会核对所见任务；任务时段、课节或完成记录发生变化时拒绝旧操作，数据库保存时再次检查同步后的版本。确认窗口显示失败原因并保留输入，其他任务独立新增的完成记录保留。
- Mac 保存课程、固定事项、学习记录或学习设置时，若数据库中的新版本与旧操作冲突，会读取最新数据更新页面并保留失败原因；编辑窗口的草稿不会被当作已保存结果。设置页可在记录草稿后点击「恢复已保存设置」载入数据库中的最新值，再重新编辑。

`Sources/StudyPersistence` 通过 `PlannerRepository` 隔离存储，SwiftData 为课程、课表、任务、完成流水和设置分别保存稳定 ID 的版本化记录；一个保存事务内更新，失败回滚。CloudKit 保持关闭；新增逻辑版本、删除标记、增量游标与单次 HTTPS 直连或 SSH 隧道同步。业务数据和同步状态在同一事务中保存。

`Sources/StudyPlanner` 负责原生界面、表单校验、生命周期与变更后自动排程。

## 本地数据与备份

Mac 课程与固定事项编辑器提供“载入已保存内容”：确认放弃未保存输入后，在原窗口载入当前日程中的记录，便于同步冲突后重新编辑；记录已删除时保留草稿并提示，不会重新创建。课程的本机软件绑定选择保留，载入本身不写入日程。

Mac 完整备份恢复在最终数据库事务中再次核对已确认的日程；核对之后到达的新确认、课程、固定事项或设置会使本次恢复停止，并刷新到最新数据供重新核对。列表的显示顺序变化不算数据冲突。

本机每日后果记录（8MB）、压缩结果缓存（32MiB）和日程备份（64MiB）在读取期间执行大小上限，文件后来增长也不能无限读入。损坏或超限的后果记录会保留，并停止覆盖写入。

Mac 在「学习设置 → 数据与备份」提供立即备份、导出 JSON、从文件恢复和最近备份列表。本机操作修改前会自动保存日程快照，最多保留最近 20 份可读备份；损坏文件保留并提示，不影响其他备份。备份只包含课程、课表、完成记录与学习设置，不含云同步凭据、播放监督绑定、自定义提示音、网站账号或网站自动更新设置。恢复全部前会备份当前日程，恢复操作会参与已开启的同步。删除课程后可在窗口顶部点「撤销删除」，或在备份列表仅恢复该课程和学习记录；其他课程的新修改保留，未确认任务按当前条件重排。监督软件需重新绑定。自动备份与原数据库在同一设备，建议另行导出到其他磁盘。

Mac 普通保存的排课、数据库写入和学习负担计算在后台完成。保存时显示进度，其他页面仍可浏览；同一时间只接受一次写入，退出会等待保存完成。失败保留原数据并提示。只修改课程名称、备注或颜色时保留现有课表；改动排程输入仍会重新排课。

跨天刷新仅在新课表保存成功后确认完成；失败后至少间隔5分钟再尝试，不会把失败当成已刷新。成功跨天后重新启用当天的学习核对提醒，Mac 会在完成刷新后检查待确认记录。

正式数据库目录：`~/Library/Application Support/StudyPlanner/`。

备份前退出软件，再复制整个目录（包括可能存在的 `.store-wal` 和 `.store-shm`），不要只复制单个数据库文件。数据库加载失败会提示错误，不会自动清空或换成空白数据库。云同步的 SSH 私钥与私钥口令保存在本机系统安全存储，不在该目录中，也不随日程同步、备份或安装包传输。

Mac 私钥文件在后台按实际字节数限量读取（最大64KB），严格检查 UTF-8 和私钥标记；读取期间暂停修改连接表单，失败保留已有密钥草稿和口令，成功导入后仍需点击保存配置才生效。

Android 首次迁移旧版 `planner-v1.json` 时，按备份相同的64MB上限严格读取 UTF-8，拒绝多余尾部内容及过深嵌套；读取失败不会保存替代日程，原文件保留。合法旧数据仍执行原有迁移，包括早期可学习时段 ID 的兼容处理。

Android 与服务端在读取备份或同步设置时，先检查分钟、星期及已知偏好等级的整数类型；小数、数字字符串与溢出值不会被截断后保存。合法的整数值 JSON 表示（例如 `60.0`、`6e1`）继续兼容，旧版未设置偏好等级的数据仍可读取。

## 验证

新增 `bash Scripts/test-ci.sh` 统一运行服务端、Swift、Android 及跨语言往返测试，自动准备并校验 JSON-java 依赖。GitHub Actions 在提交和拉取请求时执行同一入口，不上传构建产物。另有独立 Ubuntu 任务运行 `bash Scripts/test-portable-ci.sh`，用固定摘要的官方 Swift 6.0.3 容器先生成本轮样本，再验证服务端、Android 核心及真实 Android API 编译、Java 同步往返，以及全部 `StudyCoreTests` 和 Foundation 文件存储测试；最后由 Java 读取 Swift 云端快照。同步确认、浮动事项、合并记录与文件备份的互读样本在隔离目录共享，缺失样本立即失败；随后使用一次性临时密钥实际构建并验签 Android APK，核对资源、DEX、版本与空白初始数据，结束后删除临时 APK 和密钥；不使用发布密钥，不上传或安装。该任务无需等 macOS 执行器。完整 Swift、SwiftData、界面与跨语言往返检查仍在原 macOS 任务运行。需要真实手机、SSH 服务器或真实网站的测试仍须单独准备环境，不代表真机验收。

真实网站诊断 `TempSiteForensics` 默认跳过，避免普通测试依赖公网和网站状态。需要手动排查时运行 `STUDYPLANNER_LIVE_SITE_FORENSICS=1 ./Scripts/test.sh --filter TempSiteForensics`；该诊断会访问学丞网站并输出响应摘要。

## Mac 学习监督

平台边界：学习监督仅支持 Mac，Android 明确不加入；以后“全部同步 / 对齐 Mac”等宽泛指令不得覆盖本约定，除非用户明确重新授权。

1. 在「课程 → 编辑课程 → 学习监督 · 对应软件」选择 `.app`，然后保存。未选择的课程不监督；点「取消监督」并保存即可移除绑定。取消课程编辑不会保存本次软件选择。
2. 首次保存绑定时申请系统通知与检测权限；如果软件没有打开，请打开后到「学习设置 → 学习监督」点击「授权并检查」。检测不会代你启动软件。若系统自动化权限被拒绝，请在「系统设置 → 隐私与安全性 → 自动化 → 学习日程」中允许对应软件；反复点击授权不会覆盖系统中已拒绝的选择。Safari 还需单独开启「开发 → 允许来自 Apple 事件的 JavaScript」；若没有「开发」菜单，先到「Safari → 设置 → 高级」开启网页开发者功能（旧版为「在菜单栏中显示‘开发’菜单」）。开启后再次点击「授权并检查」。
3. 到课时间自动开始首次检测，之后每 1 分钟检查一次，无需打开设置页。每次检测到暂停或软件未打开都立即提醒，不再需要连续两次；检测不可用不算暂停，仍按原规则连续两次不可用才提醒、同类提醒至少间隔 15 分钟，这类冷却不影响暂停提醒。只监督未确认且正在其具体开始/结束时间内的任务；浮动任务按当前课表排列出的具体时间检查，不会要求整个浮动窗口里的所有课程同时播放。没有学习任务、休息、已完成及未绑定的课程不检查。
4. 已绑定软件时，关闭主窗口后继续后台监督；菜单栏可打开主窗口或明确退出。主动退出、电脑休眠、屏幕休眠或会话未激活时停止/暂停，唤醒后自动检查当前课程，不补发错过的提醒。不同桌面、全屏和被遮挡窗口无需切换到前台；检测不激活软件、不切换标签页、不控制播放。

监督通知默认使用系统提示音，前台和后台均请求播放；旧版升级后可点「授权并检查」，并在「系统设置 → 通知 → 学习日程」开启「播放通知声音」，声音仍受系统通知设置和专注模式限制。

在「学习设置 → 学习监督 → 监督提醒提示音 · 此 Mac」点「选择音频…」可以为这台 Mac 换一段自定义提示音，支持 MP3、M4A、WAV、AIFF、CAF 等系统可读取的单声道或双声道音频，需短于 30 秒且不超过 30MB。导入后立即生效，原文件之后移走或删除也不影响播放；该提示音只在本机使用，不参与同步。这里可以「试听」「停止试听」，用「发送测试通知」确认系统通知里的实际效果，或点「恢复默认」换回系统提示音。若音频文件丢失，提醒暂时改用系统默认提示音；导入失败时保留原来的选择。

Safari（含 Technology Preview）、提供 Chromium 脚本接口的浏览器（例如 Chrome、夸克）、QuickTime、Music、TV、Spotify 优先通过按进程发送的只读 Apple 事件读取播放状态。浏览器遍历可读取的窗口和标签页，任一音视频正在播放即通过；没有读到播放时，已读取到的暂停状态不会被个别跨域 iframe、受限标签页或无法响应的窗口覆盖。未读到音视频且仍有页面不可读时，显示检测不可用。Safari 会保留具体的自动化权限、JavaScript 开关或读取错误，不再转入无法可靠归属共享 WebKit 进程的音频检测；其他软件仍可尝试音频方式。只返回播放状态，不读取/保存网页标题、地址或观看内容。

通用音频方式要求 macOS 14.2 及以上。先读取所选软件的系统音频输出活动；系统明确报告全部归属进程均已停止输出（或已无音频进程）时，直接判为暂停或停止，无需先验证录音权限。需要采样时，使用私有、不静音的 Core Audio tap 对所选软件及可确认归属的辅助进程采样 5 秒，需要系统音频录制权限；只在内存中累计音量活动，不保存或上传音频，不截图、不更改默认声音设备。连续检测到至少 1 秒有效音频即视为播放；静音、极低音量视频可能无法识别。无法确认已停止输出且未收到有效采样时，仍显示「检测不可用」，不会把采样故障算作暂停。输出仍活跃时，首次静默采样需真实有声播放验证权限；验证成功后，有效的静默采样才计为未播放。不能可靠归属的共享音频进程不会用其他软件的声音代替。

权限不足或状态不可读会明确显示「检测不可用」，不会记作未学习，也不改变学习完成记录或排程；持续不可用时发送配置提醒。系统通知仍受通知权限和专注模式限制。`Scripts/test-playback.sh` 可在安装 Swift 6 的 Linux/macOS 环境运行授权结果与检测回退的回归测试；macOS 完整测试可运行 `./Scripts/test.sh --filter PlaybackDetectionTests`。这些测试不代表真实软件、跨桌面、系统授权和通知投递已验收。

## MVP 边界

- 采用截止日期优先与有限碎片修复的启发式算法，不是任意时间块组合的全局最优求解器。Mac 的联合补排搜索目前最多处理 6 门课、600 个待排块、366 个浮动事项，要求单日最多一个且连续占用不少于 15 分钟，并受搜索预算限制；超出范围或预算返回待优化，不能据此证明无解。只有找到完整课表才替换原方案。已证实的容量下界缺口与连续空档冲突单独报告。Android 沿用原排程和风险入口。
- 最多生成未来十年；极端碎片情况的搬移搜索最多 200 次，避免在不可完成负载下长时间卡住。
- 当前不支持拖拽锁定某个自动任务、跨午夜固定事项（需要分两条）、隔周/单双周或按节假日排除的复杂重复规则。可通过修改课程、固定事项和每日可用时间调整计划。
- 网站导入在 macOS 和 Android 提供。研途（`www.kaoyanvip.cn`）依赖前端模块结构定位接口；学丞教育（`ixuecheng.cn`）的回放读取依赖目录与播放器页面结构。网站改版后需要更新对应抓取脚本；未读到可靠回放时长时会阻止该课程生成计划。其他 HTTPS 课程网站可用通用 JSON 识别，但需要人工核对结果。手动导入时，Mac 只读取用户明确连接的默认浏览器课程标签页；课程列表的「网站来源与更新」则在应用运行期间按间隔更新已绑定网址的课程。
- 网站进度折算成课程的「已完成基础量」，同时用于计算每节剩余时长；应用内确认课节任务后会按课节更新余量。手动导入的抓取由用户发起，或在导入窗口打开、连接有效时每 5 分钟刷新一次，关闭导入窗口后不再读取；后台网站自动更新是另一条路径，只在应用运行且对应来源已开启时按所设间隔检查，不依赖导入窗口。真实默认浏览器授权、网站账号登录、跨域直播回放、钥匙串读取和导入操作仍需从 DMG 安装后验收；自动化测试使用合成网页与内存设置，不代表真实网站账号、默认浏览器自动化或 macOS 钥匙串的实机验收。
- 内置日历与应用内确认，不提供系统日历同步或独立后台守护进程。Mac 学习监督在应用进程中运行，并使用本地系统通知；退出应用后不继续监督。
- 云同步的 SSH 方式只把服务器本机 `127.0.0.1:18090` 转发给 App 使用，对应普通用户安装的默认监听；系统级安装的 `127.0.0.1:8787` 仍按 HTTPS 反向代理接入。SSH 方式不执行远程命令、不通过 SFTP 管理服务器文件，也不替代服务器自身的备份与访问码管理。

文字识别的重复事项未写开始日期时，从识别当天起按重复星期安排，避免把“每周一、三、五”误推到下周。明确写“从周五开始”“明天起”时保留该开始日期，开始标记中的星期不额外加入重复星期；识别结果仍需在编辑页核对并保存。 候选名称会去掉日期起止说明、重复星期和时长说明，保留事项名称与原文；无法确定名称时明确提示补充。

重复事项识别支持“从下周开始”“下下周起”“从本周开始”，统一以周一划分星期，并保留明确的截止日期；同一条同时出现相互矛盾的开始日期时要求重新核对，不生成候选。

课程管理可在“截止日期优先”和“课程优先级优先”之间切换；优先级从高到低，同级按截止日期排列。排序与关键词、排程状态筛选组合使用，只改变列表展示，不修改课程或排程。Android 切换排序回到第一页，翻页和页面重建保留选择。

Mac 合并课程会在最终数据库事务中再次核对所选课程和已记录的学习进度。预览后发生相关同步修改时停止合并并刷新最新数据，保留所选课程和名称供重新核对；无关课程修改和未确认任务的重新安排不会阻止合并。

Mac 合并选课窗口支持后台搜索课程名称、备注、截止日期，以及“只看已选课程”；筛选不改变选择，保存仍合并全部已选课程。同步删除或归档已选课程后，会明确取消这些失效选择，保留其余选择和合并名称，避免隐藏的旧选择阻止继续操作。

重复事项识别支持混合星期区间，如“每周一至三、五”“每周五到一、三”，逐段展开后合并；数字和全角写法“每周1-3,5”不会误作月日。名称和通知原文保留，识别后仍需核对候选再保存。

文字识别遇到隔周、单双周、按月或按间隔重复、节假日除外及顺延等暂不支持的规则时，会说明原因并保留原文，不再简化成单次或普通每周事项。分行共用的重复规则同样保留用于核对；同段的其他明确日程仍可生成候选。

事项时长支持“半小时”“半个小时”“1.5 小时”“0.75 小时”等写法，并与起止时间交叉核对；互相矛盾、非整分钟、零时长或跨午夜的内容要求修改后再识别，不会静默舍入或替换成默认时长。

多条活动可共用日期或重复规则标题；每行只有开始时间时也能分别识别，后续活动不会继承上一条的名称或专属时长。无时间的公共标题可统一指定时长，学期开始和截止日期继续保留；明确跨行写出的“09:00 到 10:00”仍视为一条区间。

Mac 固定事项列表支持组合搜索名称、备注和起止日期（YYYY-MM-DD），兼容全角关键词，并可叠加星期筛选；单次事项只按实际发生日期匹配。筛选与排序在后台进行，保留已完成分组和临时跳过的规则，切换关键词不会显示过期搜索结果。
