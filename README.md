# 学习日程

一个本地优先的学习计划应用：录入课程、固定课表和可学习时间后，自动把学习任务安排到截止日期前。提供 macOS 与 Android 两个原生客户端，并可在同一局域网内按需同步。

本仓库及公开发布的安装包不包含任何个人课程、课表、任务、完成记录、备份或配对凭据。首次打开是空白日程。

macOS 14 及以上（Apple Silicon）可使用 macOS 版本；Android 8.0 及以上可使用 Android 版本。

## 运行

双击 `dist/学习日程.app`。首次打开为空白数据库，可以直接添加课程，或点击「载入示例，体验自动排程」。示例一旦通过正式应用的按钮载入，也会保存在本机。

开发环境需要 Xcode / Swift 6：

```sh
./Scripts/test.sh
./Scripts/build-app.sh
```

也可在 Xcode 中打开 `Package.swift`，选择 StudyPlanner 运行。打包脚本默认 Release；传入 `debug` 可构建调试版。本机构建使用临时 ad-hoc 签名，尚未制作 Developer ID 公证的对外发行版本。

隔离预览：运行 `.build/debug/StudyPlanner --demo`，所有示例操作仅使用内存数据库。不会改动正式数据库。

## 已实现

- 学习课程新增、编辑、删除（内部归档保留历史）；总量、导入进度、截止日、开始日、优先级、颜色、备注、可选发布时间、自动排程开关。
- 固定事项、每周多个星期重复、单次考试或会议、学期起止日期与持续周数；检测固定事项之间及正在进行的任务冲突。
- 每周每天多个可学习时段；休息日、全局与课程级自定义最小时间块。
- 独立月历、当天时间轴、课程进度与每日建议。
- 完成、部分完成、未完成、提前完成；批量每日确认，跨天与下次启动补查未确认记录。
- 自动重排、历史与正在进行的任务保护、容量风险提示与调整入口。
- SwiftData 本地持久化、保存失败回滚、启动失败时明确报错且不覆盖已有数据。

没有 EventKit、系统日历事件或云服务器。按需同步仅连接 Android 手机热点局域网，详见 [同步使用与实现报告](同步说明.md)。代码里的 `Foundation.Calendar` 仅用于日期和星期运算，与 macOS Calendar 应用无关。

## 使用流程

1. 在「学习设置」录入每天可学习时段并保存。
2. 在「固定课表」添加学校课、补习班及休息时间。重复日期按本地星期计算；开始日和结束日均包含在内。
3. 在「课程管理」录入总小时数、已完成基础量和截止日期。基础量与应用内已确认的进度相加。
4. 在日历查看安排。圆圈按钮确认全部完成；省略号可填写实际完成分钟数。未来日期同样支持操作。
5. 晚间确认时间之后，或第二天首次打开时，确认未完成计划。每项都需要明确选择，避免默认把未勾选项目算作漏学。
6. 出现橙色风险提示时，增加可用时间、修改截止日期或最小时间块。

应用关闭时不在后台执行；下次打开时补查并重排。跨天检查每 30 秒进行，重新激活窗口时也检查。

## 排程语义与架构

`Sources/StudyCore` 不依赖 SwiftUI 或 SwiftData。

- `Course` 保存总分钟数与导入进度，`CompletionRecord` 是完成流水。剩余量 = 总量 − 导入进度 − 已确认流水；计划本身不扣减进度。
- `ScheduledTask` 保存原计划及确认状态。重复确认会被拒绝。未完成不增加额外债务，只保留尚未学完的量。
- `ScheduleEngine.generate(state:now:)` 是纯函数。输入日期、固定课表、可用时段、课程与完成记录，输出未来任务、每日建议和风险诊断。
- 先合并可学习时段、扣除固定事项和进行中的任务，再按截止日期、每日需求、用户优先级分配连续时间块。对碎片进行有限的搬移修复，然后平衡各课程每日负担，在原空闲区间内整理、穿插课程。
- 所有计算使用整数分钟，区间为左闭右开；截止日期包含当地当天。最后一个不足最小单位的尾块允许缩短，保证不凭空增加学习量。
- 进行中的未确认任务保留并预留其学习量，避免重复安排；已结束但尚未确认的历史任务不计入已完成，余量继续进入新计划。之后再确认历史任务，未来负担相应减少。
- 历史和已确认任务不被自动删除。提前完成的记录单独展示，不继续占用未来时间轴。
- 固定课表编辑会拆分历史与未来规则；当天已经开始的那次课也保留。删除课程在内部使用归档，以保留历史关联。

`Sources/StudyPersistence` 通过 `PlannerRepository` 隔离存储，SwiftData 为课程、课表、任务、完成流水和设置分别保存稳定 ID 的版本化记录；一个保存事务内更新，失败回滚。CloudKit 保持关闭；新增逻辑版本、删除标记、增量游标与单次 HTTPS 同步。业务数据和同步状态在同一事务中保存。

`Sources/StudyPlanner` 负责原生界面、表单校验、生命周期与变更后自动排程。

## 本地数据与备份

正式数据库目录：`~/Library/Application Support/StudyPlanner/`。

备份前退出软件，再复制整个目录（包括可能存在的 `.store-wal` 和 `.store-shm`），不要只复制单个数据库文件。数据库加载失败会提示错误，不会自动清空或换成空白数据库。

## 验证

单元测试覆盖均摊、漏学守恒、提前完成、部分完成、重复确认、历史保护、正在进行的任务、固定冲突、每周重复、跨课程截止压力、开始日容量、碎片修复、30 分钟块、最终余量、无可用日、设置修改、每日确认、课程归档与磁盘重开。还包含 40 组多课程生成场景的时间不重叠和学习量守恒检查，以及 1000 小时不可完成负载的响应时间检查。

已用实际原生窗口检查月历、课程录入、提前完成、部分完成、风险警告及风险到设置的跳转；UI 检查在独立内存预览中进行。

## MVP 边界

- 采用截止日期优先与有限碎片修复的启发式算法，不是任意时间块组合的全局最优求解器。容量不足时明确报告数学上的缺口；容量够但当前算法不能排满时，会明确区分为「时间块安排仍有学习量未排入」，不会宣称已经全部安排成功。
- 最多生成未来十年；极端碎片情况的搬移搜索最多 200 次，避免在不可完成负载下长时间卡住。
- 当前不支持拖拽锁定某个自动任务、跨午夜固定事项（需要分两条）、隔周/单双周或按节假日排除的复杂重复规则。可通过修改课程、固定事项和每日可用时间调整计划。
- 内置日历与应用内确认，不提供系统日历同步、后台守护进程或系统通知。
