# 学习日程

把固定课表、不定时课程和可学习时段录入后，自动按截止日期智能排序学习任务，并安排到合适的时间。「学习计划」支持 macOS 与 Android，可在同一局域网内同步数据。

本仓库及公开发布的安装包不包含任何个人课程、课表、任务、完成记录、备份或配对凭据。首次打开是空白日程。

macOS 14 及以上（Apple Silicon）可使用 macOS 版本；Android 8.0 及以上可使用 Android 版本。

## 运行

运行 `./Scripts/build-app.sh` 可生成开发构建 `dist/学习日程.app`。对外分享请运行 `./Scripts/release.sh`，脚本会生成 macOS DMG、Android APK、安装说明、SHA-256 校验和及可直接转发的 ZIP。首次打开为空白数据库，可以直接添加课程，或点击「载入示例，体验自动排程」。示例一旦通过正式应用的按钮载入，也会保存在本机。

开发环境需要 Xcode / Swift 6：

```sh
./Scripts/test.sh
./Scripts/build-app.sh
```

也可在 Xcode 中打开 `Package.swift`，选择 StudyPlanner 运行。打包脚本默认 Release；传入 `debug` 可构建调试版。本机构建使用临时 ad-hoc 签名，尚未制作 Developer ID 公证的对外发行版本。

隔离预览：运行 `.build/debug/StudyPlanner --demo`，所有示例操作仅使用内存数据库。不会改动正式数据库。

两端构建版本统一从 `Scripts/version.env` 读取，目前为 1.4.4（构建号 9）。本地运行版位于 `dist/本地运行版-1.4.4/`：Mac 应用和 Android APK 使用同一版本，Android 沿用已有本地签名。该版本修复网站刷新与旧快照导入时的进度丢失，按课节核对网站与本地重叠量；撤销确认仍保留网站已验证进度，合并课程与 Android 同步采用相同计算。也保留 1.4.3 的每日学习时段重排修复：已确认进度、往日记录和固定事项保留，重开与再次重排不会累计同一份课表。当前工作目标为本地稳定运行，正式公证和跨设备发布验收暂缓。

## 已实现

- 学习课程新增、编辑、删除（同时清除全部安排和完成记录）；总量、导入进度、截止日、开始日、优先级、颜色、备注、可选发布时间、自动排程开关。
- 固定事项支持「固定时间」与「时段内浮动」：指定窗口和连续占用分钟数，只预留实际时长。窗口内的学习任务使用虚线卡片、双向箭头和「时段内完成」标签；浮动事项另有占用比例条。两端均保留浮动字段并参与同步，旧数据继续按固定时间读取。
- 固定事项、每周多个星期重复、单次考试或会议、学期起止日期与持续周数；检测固定事项之间及正在进行的任务冲突。
- 在主页日历选中今天或未来某日，点击对应固定事项占位卡片的「仅此日移除并重排」，即可释放这一天的占用并重排今天及未来未确认课程；今天已经开始的事项也可临时取消。其他日期的重复规则、往日记录和已确认进度保留。「本日已临时移除」提供恢复入口，恢复前检查固定事项冲突。固定时间、浮动事项和单次事项均支持，移除日期随数据保存与同步。
- 冲突详情按日期列出事项名称、起止时间、重叠时段和分钟数；浮动容量不足会解释原因；未确认的学习任务允许自动移动。每个日期可独立确认跳过，也可「全部跳过并保存」。同一天的多个冲突统一处理，只跳过当前编辑的事项；未确认的冲突仍阻止保存，已有事项与历史记录保留。
- 每周每天多个可学习时段；休息日、全局与课程级自定义最小时间块。
- 独立月历、当天时间轴、课程进度与每日建议。
- Mac 主页今天及未来日期的未确认课程板块支持长按约半秒后拖动：拖到另一课程或同一套课的另一课节板块上松开，交换本日两块的位置；目标高亮并显示「松开交换」，落在空白处取消。保留课程时长、固定事项及课间休息，仅调整选中日期，松开后立即播放交换动画并在后台保存，失败会恢复原安排；退出应用会等待本次保存完成。顺序保存后重开仍沿用。当天空间不足时保留原安排并提示；后续更改学习量或可用时段导致顺序不可行时，自动排程优先保证时间约束。拖动以低优先级手势挂载，课程块上的「确认完成」与「部分完成/未完成」按钮点击照常响应，只有按住约半秒才进入拖动。
- Mac 主页课程进度旁显示总学习负荷：达到理论容量的 80% 显示醒目橙色警告，超过 100% 显示红色最高警告，并计算连续不学习多少天会触发下一等级。按完整自然日检查课程开始日与各截止节点，包含暂停排程的未完成课程；仅扣除每天重复的固定事项，非每日事项与最小时间块仍由实际排程处理，因此低于上限不保证实际可排完。
- 完成、部分完成、未完成、提前完成；批量每日确认，跨天与下次启动补查未确认记录。
- 自动重排（今天的未确认课程实时调整）、历史与已确认记录保护、容量风险提示与调整入口。
- 主页可输入「今日实际开课时间」并点击「生成新课表」：替换今天尚未确认的旧安排（包括已过计划时间但未确认的课程），从输入时间重新计算今天和后续学习任务。遵守可学习时段、固定事项、课间休息与截止日期，保留已确认进度和往日记录；时间随数据保存与同步，仅在输入当天生效，次日重新输入。允许补录早于当前时间的实际开课时间，重新打开也沿用这个时间展示新课表。
- macOS 可从课程网站读取账号下的课节时长与观看进度，一次性生成或更新学习课程；抓取不完整时整体拒绝导入（见下节）。导入后自动使用「不定时录播课程」，每节按剩余时长生成独立任务，也可手动录入课节。抓取窗口左侧核对课程和编排预览，右侧操作网页。
- 已添加的课程可在 macOS「课程 → 合并课程」中多选合并并预览：课节默认按课程、阶段、章节和课节编号智能正序排列，支持末尾编号、中文序号、前导零和上中下；之后可在「调整课节顺序」中点击「智能排序」预览应用，或继续手动调整。原课程从独立课程列表移除，来源信息、完成记录和正在进行的任务转入合并课程；采用最早的开始日期与截止日期，未分课节的课程作为一节。手机端需使用包含合并课程兼容逻辑的新版排程器。
- 按节课程可在课程列表点击「调整课节顺序」，多选课节后移到最前、最后或指定序号；左侧顺序与右侧重新编排预览同步更新。保存后从当前时间重排今天及以后的未确认任务；已结束和已确认记录保留。网站再次抓取时保留手动顺序，新出现的课节接在后面。
- SwiftData 本地持久化、保存失败回滚、启动失败时明确报错且不覆盖已有数据。
- 通过手机热点按需双向同步；首次配对由 Mac 生成一次性二维码、Android 扫描，不需要复制配对串。

没有 EventKit、系统日历事件或云服务器。按需同步仅连接 Android 手机热点局域网，详见 [同步使用与实现报告](同步说明.md)。代码里的 `Foundation.Calendar` 仅用于日期和星期运算，与 macOS Calendar 应用无关。

## 使用流程

1. 在「学习设置」录入每天可学习时段并保存。
2. 在「固定课表」添加学校课、补习班及休息时间。重复日期按本地星期计算；开始日和结束日均包含在内。
3. 在「课程管理」录入总小时数、已完成基础量和截止日期。基础量与应用内已确认的进度相加。macOS 也可以从课程网站抓取课节（见「从课程网站导入课程」）。按节课程创建后，可在课程卡片点击「调整课节顺序」批量移动课节并重新排程。
4. 在日历查看安排。圆圈按钮确认全部完成；省略号可填写实际完成分钟数。未来日期同样支持操作。
5. 晚间确认时间之后，或第二天首次打开时，确认未完成计划。每项都需要明确选择，避免默认把未勾选项目算作漏学。
6. 出现橙色风险提示时，增加可用时间、修改截止日期或最小时间块。

补确认已结束的任务（包括批量全部完成）会重新排程，扣减未来重复安排的学习量；撤销确认也会重新排程，恢复尚需完成的学习量。浮动任务以整个完成窗口结束为准。「载入示例」仅在没有课程、固定事项、任务和完成记录时可用。

应用关闭时不在后台执行；下次打开时补查并重排。跨天检查每 30 秒进行，重新激活窗口时也检查。

## 从课程网站导入课程（macOS）

在「课程管理 → 从网站抓取全部课程」打开抓取窗口。右侧内置 WebKit 页面用于正常登录并进入课程列表或详情；左侧显示抓取结果、课节和编排预览。顶部地址栏可自由输入网址（省略 `https://` 会自动补全），回车或点「打开」即在该窗口内访问，「恢复默认地址」回到研途「我的课程」。

抓取按站点自动选择模式。

**研途：专用适配器。** 进入「我的课程」后自动抓取一次，也可以随时点「重新抓取全部课程」，或勾选「每 5 分钟刷新」。抓取的是当前登录账号下的正式课与体验课，包含已隐藏的课程包；已失效的课程包只列出名称和原因，不读取课节也不能导入。

**其他网站：通用识别。** 窗口在页面最早阶段注入一个嗅探器，记录该页面自己发出的同源 JSON 响应——它不发起任何新请求，也不读取 Cookie、令牌或请求头。登录后打开「我的课程」，再逐门点开课程目录；每打开一门，程序就在这些响应里用字段启发式还原课程与课节并自动累加到列表，可以连着点开多门，也可手动点「重新识别课程」。

**学丞教育：逐层读取目录与直播回放。** 打开 `ixuecheng.cn/detail` 后，程序会按顺序遍历各层章节，包括只有箭头的二级目录。网站的分组互斥展开，程序会先等待当前分组加载并保存结果，再读取下一组，不再反复尝试将所有组同时展开。后台识别复用本轮已读取的目录；「重新识别课程」或每 5 分钟刷新才重新遍历。已发布直播按保存的章节位置打开回放，从嵌入的回放页读取播放器时长或直播起止时间；失败的回放本轮不循环重试。尚未开播的直播保留为未发布条目。回放链接含临时鉴权信息，仅在当前 WebKit 会话中使用，不写入课程快照；回放页没有提供可验证的观看进度时按 0% 估算。已发布回放若无法读取时长，该课程不能生成计划。

还原规则：识别常见命名（`name`/`title`、`duration`/`videoDuration`/`length`/`seconds`、`percent`/`progress`/`schedule` 等）；时长既接受数字，也接受网站已经格式化好的文本（`45:30`、`01:02:03`、`45分钟`、`1小时20分`）；按「有名称且有时长或进度」判定课节，纯章节节点不会被当成课节；课节若自带课程编号（如 `courseId`），同一门课的多个章节会合并成一门课程，没有课程编号时退回到「最外层列表项」分组。单位按整份响应统一换算（毫秒与秒、0–1 比例与 0–100 百分比），避免把「1%」读成「100%」。课程名按「课节自带的课程名 → 响应根节点名称 → 页面标题 → 域名」的顺序兜底。

学丞的空章节（包括只有空目录容器、没有提示文字的章节）在同源请求结束且页面稳定后正常跳过，继续读取后续章节；整门课程为空时显示暂无可读取课节。仍在请求或加载中的章节会继续等待，请求失败或超时会明确提示原因。

通用识别只认页面已经加载过的数据；学丞教育直播回放使用上面的专用补充读取。其他网站若必须逐节点开才返回时长，就得逐门点开（点开的结果会累积，不会互相覆盖）；网站没给时长的课节不计入总学习量但仍保留在列表里，没给进度的按未观看计入。识别出的课程名、节数与总时长请在窗口内核对后再生成计划。

每个课程包依次读取全部科目（大纲）、阶段、章节和课节，并合并直播课节。研途模式下每个课节记录时长、网站观看进度、是否发布、是否被手动标记完成；直播课节不猜时长和进度。观看比例只来自网站，手动完成标记不会覆盖实际观看比例，也不作为已完成学习量。

导入是整体成功或整体失败：只要有一个课程包抓取不完整（分页数量不一致、某个科目请求失败、已发布课节缺少时长或缺少观看进度、课节编号重复、返回的时长或进度越界），该课程包会被标出原因且不能勾选；存在任何全局问题时，「导入并生成计划」保持禁用。默认勾选所有没有问题的课程包，可自行取消。

生成计划时，总学习量按合计秒数向上取整到分钟；「已完成基础量」按课节核对网站观看量与应用内流水，只扣除同一课节中重叠的进度。网站已记录的基础进度、其他课节的本地完成量和抓取之后的新确认都会保留；重复刷新不会重复累计。没有课节标识的旧流水沿用保守的总量核对。撤销本地确认时仍保留网站已验证的观看量，合并课程也适用。网页课程自动改为按课节排程，一节对应一项任务；默认按照网站返回的科目、章节与课节顺序学习，只有用户在课节顺序编辑器中选择「智能排序」或手动移动时才改用自定义顺序，编辑器也提供「按网站顺序」恢复。再次抓取时，跟随网站顺序的课程会同步网站的新顺序，用户自定义顺序保持不变。剩余时长无法放入连续空档时会显示未排入风险。课程编辑页和导入结果都能查看逐节编排预览。保存按课程包编号匹配已有课程：未归档的已有课程保留开始日、截止日和优先级；重新导入已删除课程按新课程处理，从今天排至所选截止日；原应用内完成记录不会恢复。新课程也使用所选截止日（默认 90 天后，可选当天起十年内）。

网页会话使用非持久化数据存储：登录只在本次窗口内有效，关闭窗口即停止读取并释放会话。研途适配器只调用该站自身的只读 GET 接口，复用页面已登录的请求封装；通用嗅探器只旁观页面自己发出的同源 JSON 响应；学丞教育回放读取通过页面自己的点击入口打开回放。抓取器不导出、不保存、不上传任何 token，也不读取 Cookie、令牌或请求头。页面内导航仅允许 HTTPS，地址栏也只接受 HTTPS（缺省协议会补成 HTTPS）。抓取限定在地址栏所在的站点：页面一旦跳到别的域名，自动抓取与「重新抓取」都会停用，避免误读其他站点。研途脚本依赖其前端的模块命名来定位接口，网站改版后会明确提示「研途网页已更新」；通用识别则会如实报告「捕获了 N 个接口但没有识别到课程结构」，不会用猜测的数据凑数。Android 尚无网页导入入口，导入后的总学习量与进度可通过现有同步功能同步到手机。

自动化测试用本地 WebKit 页面驱动真实注入脚本，覆盖分页列表、科目与阶段章节解析、观看进度、未发布课节、重复课节去重，以及单个科目失败时不计为完整课程；地址栏补全、HTTPS 校验与同站点判定另有纯函数测试。通用识别另有 14 个纯函数用例，覆盖嵌套章节归并、按课程编号合并同一门课的章节、多门课程拆分、毫秒换算、格式化时长与百分比文本、单位与比例的整响应一致性、无时长课节不阻塞导入、播放位置换算进度、跨接口去重合并，以及无课程数据时返回空结果。

## 从夸克网盘导入课程（macOS）

在「课程 → 从夸克网盘导入」粘贴 `https://pan.quark.cn/s/...` 分享链接；链接若指向 `#/list/share/<目录编号>`，会从该子目录开始。页面加载后自动递归读取文件夹和分页，识别视频、按目录与讲次自然排序，在左侧展示课程候选与每节课。提取码分享可在窗口填写提取码；需要登录时可在右侧页面登录后重新读取。读取只访问夸克的分享令牌与目录接口，不转存、下载或修改云盘文件。

识别结果按分享目录折叠成大分类，每个分类可批量勾选或清空。分类小标题和课程名称以更大的加粗字体显示。搜索框支持课程名、目录路径和课节名；搜索后可批量勾选或取消匹配结果，也可点击课程卡片的「定位课程」，清除搜索、展开所属分类并滚动到完整目录中的对应课程，蓝色边框和「已定位」标识便于确认位置。定位保留已有勾选。顶部「全部勾选」「全部不勾选」作用于整份识别结果，其中无法导入的课程不会被勾选。课程卡片显示原目录路径，便于核对名称相近的候选。

勾选至少两门候选课后，可打开「将已选课程合并为一门」，编辑合并后的课程名称并预览课节。合并时先按来源课程，再按章节和课节编号智能排序，原文件路径和来源课程仍保留；导入后在课程卡片中点「调整课节顺序」可手动重排。再次以相同候选课组合导入会更新同一门合并课程，并保留已设置的课节顺序。

课程判定结合视频占比、目录和文件名中的课程词、连续讲次、视频数量及时长。特征较弱的候选不会默认勾选，仍可人工核对。课内同名同讲次的文件按大小、时长、清晰度识别：接近的副本导入时只保留最佳的一份，明显不同的版本全部展示并提示核对；跨文件夹的课程按课节集合与时长、体积比较，只有课节完整一致且信息接近的课程才默认去掉一份。与已有计划高度重合的课程也不会默认勾选。目录未读完时禁止导入，避免形成残缺计划。导入后保存分享来源、原文件路径、时长估算与查重摘要；分享令牌不写入本地课程数据。

命令行可用 `学习日程 --netdisk-probe '<分享链接>'` 只读检查课程识别与查重摘要。夸克网页接口可能变化，届时会明确显示解析或请求错误。

## 排程语义与架构

`Sources/StudyCore` 不依赖 SwiftUI 或 SwiftData。

- `Course` 保存总分钟数与导入进度，`CompletionRecord` 是完成流水。剩余量 = 总量 − 导入进度 − 已确认流水；计划本身不扣减进度。
- `Course.webCourse` 保存最近一次网站抓取快照（课程包编号、各课节时长与观看进度、抓取时间与问题列表）。`Course.manualLessons` 保存手动录入的课节。快照和课节随课程记录同步；Mac 与 Android 均按逐节剩余时长排程。
- 网站抓取输出同一个 `WebCourseSnapshot`：研途走注入页面的 `CourseCrawler.js`（依赖该站前端模块命名，自行分页遍历全部课程包）；其他站点走 `GenericCrawler.js` 嗅探页面自己的同源 JSON 响应，再由纯函数 `GenericCourseDigest` 用字段启发式还原课程与课节。学丞教育课程详情页另外展开直播目录，逐项进入已发布回放，并从回放页读取时长；未取得时长的已发布回放会阻止该课程生成计划。导入流程与全部校验对各通路一致，因此持久化、同步与 Android 端无需区分来源。
- `ScheduledTask` 保存原计划及确认状态。重复确认会被拒绝。未完成不增加额外债务，只保留尚未学完的量。
- `ScheduleEngine.generate(state:now:)` 是纯函数。输入日期、固定课表、可用时段、课程与完成记录，输出未来任务、每日建议和风险诊断。
- Mac 与 Android 的相邻课节或学习块之间至少保留 15 分钟间隔（同一课程也适用），休息不计入学习进度。间隔跨可学习窗口与午夜保留；重新排程也保留已确认或刚结束任务后的休息。最后一节不需要在可用时段内额外预留尾部休息，排不下的学习量显示未排入风险。
- 先合并可学习时段、扣除固定事项和保留的历史占用，再按截止日期、每日需求、用户优先级分配连续时间块。修复碎片后尝试按天轮换：同优先级优先安排当天学习量较少的课程，让满课日也能交错多门课，轮换会跨越当天不同空闲时段。保持课节内部顺序、整节时长和截止日期；只有全部已排入任务仍能容纳时才采用新方案，否则保留原可行排程。最后平衡每日负担并整理时间。
- 浮动事项先计算一组窗口内互不冲突的连续占用位置，作为容量计算依据；这些位置不会显示为真实预约时间。多个浮动窗口可以重叠，占用时长累计。组合搜索有上限，无法找到安排时提示调整窗口。受影响的学习任务保存完成窗口；窗口开始后仍可从当前时间重新安排，旧的未结束计划会被替换，窗口结束后再进入待确认。
- 所有计算使用整数分钟，区间为左闭右开；截止日期包含当地当天。最后一个不足最小单位的尾块允许缩短，保证不凭空增加学习量。
- 计划已开始不代表实际已学习，未结束且未确认的任务全部参与重排（包括浮动窗口），不再预留或锁定；已结束但尚未确认的历史任务不计入已完成，余量继续进入新计划。之后再确认历史任务，未来负担相应减少。
- 历史和已确认任务不被自动删除。提前完成的记录单独展示，不继续占用未来时间轴。
- 固定课表编辑会拆分历史与未来规则；当天已经开始的那次课也保留。删除课程会同时移除全部安排和完成记录；旧版本通过归档移除的课程会在读取时清理，并通过同步传播删除。

`Sources/StudyPersistence` 通过 `PlannerRepository` 隔离存储，SwiftData 为课程、课表、任务、完成流水和设置分别保存稳定 ID 的版本化记录；一个保存事务内更新，失败回滚。CloudKit 保持关闭；新增逻辑版本、删除标记、增量游标与单次 HTTPS 同步。业务数据和同步状态在同一事务中保存。

`Sources/StudyPlanner` 负责原生界面、表单校验、生命周期与变更后自动排程。

## 本地数据与备份

正式数据库目录：`~/Library/Application Support/StudyPlanner/`。

备份前退出软件，再复制整个目录（包括可能存在的 `.store-wal` 和 `.store-shm`），不要只复制单个数据库文件。数据库加载失败会提示错误，不会自动清空或换成空白数据库。

## 验证

真实网站诊断 `TempSiteForensics` 默认跳过，避免普通测试依赖公网和网站状态。需要手动排查时运行 `STUDYPLANNER_LIVE_SITE_FORENSICS=1 ./Scripts/test.sh --filter TempSiteForensics`；该诊断会访问学丞网站并输出响应摘要。

单元测试覆盖均摊、漏学守恒、提前完成、部分完成、重复确认、历史保护、正在进行的任务、固定冲突、每周重复、跨课程截止压力、开始日容量、碎片修复、30 分钟块、最终余量、无可用日、设置修改、每日确认、课程归档与磁盘重开。还包含 40 组多课程生成场景的时间不重叠和学习量守恒检查，以及 1000 小时不可完成负载的响应时间检查。

浮动事项覆盖窗口内连续占用、多个重叠窗口的容量累计、占用时长校验、窗口开始后实时重排，以及窗口结束才进入待确认的时机；冲突详情覆盖逐日列出重叠时段与分钟数、每个日期独立跳过、「全部跳过并保存」的原子性，以及未确认的学习任务可以让位于新事项。学习负荷覆盖 80% / 100% 阈值、自然日口径和暂停排程的未完成课程。网站导入覆盖快照编解码与旧数据兼容、按课程包编号的幂等更新、完成量与网站观看量不重复累计，以及任一课程包不合格时整体不写入。

抓取脚本用本地 WebKit 页面驱动真实注入的 `CourseCrawler.js`，覆盖分页列表、科目与阶段章节解析、观看进度、未发布课节、重复课节去重，以及单个科目请求失败时该课程包不计为完整课程。测试覆盖按课节排程、部分完成、连续空档不足、网页回放读取及 Android 同步排程。

已用实际原生窗口检查月历、课程录入、提前完成、部分完成、风险警告及风险到设置的跳转；浮动事项虚线卡片、冲突详情窗口与学习负荷警告在独立内存预览中检查。

## MVP 边界

- 采用截止日期优先与有限碎片修复的启发式算法，不是任意时间块组合的全局最优求解器。容量不足时明确报告数学上的缺口；容量够但当前算法不能排满时，会明确区分为「时间块安排仍有学习量未排入」，不会宣称已经全部安排成功。
- 最多生成未来十年；极端碎片情况的搬移搜索最多 200 次，避免在不可完成负载下长时间卡住。
- 当前不支持拖拽锁定某个自动任务、跨午夜固定事项（需要分两条）、隔周/单双周或按节假日排除的复杂重复规则。可通过修改课程、固定事项和每日可用时间调整计划。
- 网站导入仅在 macOS 提供。研途（`www.kaoyanvip.cn`）依赖前端模块结构定位接口；学丞教育（`ixuecheng.cn`）的回放读取依赖目录与播放器页面结构。网站改版后需要更新对应抓取脚本；未读到可靠回放时长时会阻止该课程生成计划。其他 HTTPS 课程网站可用通用 JSON 识别，但需要人工核对结果。不监控外部浏览器。
- 网站进度折算成课程的「已完成基础量」，同时用于计算每节剩余时长；应用内确认课节任务后会按课节更新余量。抓取由用户发起或每 5 分钟自动刷新一次，窗口关闭后不再读取。
- 内置日历与应用内确认，不提供系统日历同步、后台守护进程或系统通知。
