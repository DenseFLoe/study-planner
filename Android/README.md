# 学习日程 · 安卓版

安装包：`../dist/学习日程-安卓版.apk`，适用于 Android 8.0（API 26）及以上，原生 Java 界面；使用局域网 INTERNET、扫码 CAMERA 和限时前台同步服务权限，无云服务器或存储权限要求。摄像头帧仅在内存中用于识别 Mac 配对二维码，不保存、不上传。

## 安装与已有日程

把 APK 传到安卓手机，在文件管理器点开安装，按手机提示允许该来源安装应用。由于旧发布签名密码不可用，本次 1.3 已换用新签名：已安装 1.2 的手机必须先在旧版导出 JSON 备份，然后卸载旧版、安装 1.3 并恢复备份。

首次打开是空白日程，不包含课程、固定课表、任务、完成记录、备份或配对凭据。用户确认进度、修改数据、点击重排或跨天后会自动更新未来安排。

手机和电脑各自离线存储，通过热点可进行按需双向同步；详见 [同步使用与实现报告](../同步说明.md)。Android 1.3 使用 SQLite，并自动迁移旧 JSON 文件，旧文件保留为备份；首次配对改为扫描 Mac 生成的一次性二维码，不再复制配对串。应用设置中可导出与恢复 JSON 备份。未来使用当前新签名的覆盖安装会保留手机进度；卸载或清除数据会删除手机记录。内置快照仅在没有本地数据时载入，遇到损坏数据报错，不用空数据覆盖。

## 功能

- 月历、当天时间轴、完成记录、课程进度。
- 课程新增编辑、类型、总量与导入进度、起止日期、发布时间、优先级、颜色、备注、最小时间块、自动排程及归档。
- 单次与每周重复固定事项、起止日期、跳过日期、冲突检测、编辑和删除时保留历史及正在发生的事项。
- 多个每日可学习时段、休息日、全局时间块和应用内每日确认时间。
- 全部完成、部分完成、未完成、提前完成、逐项填写后批量确认；留空项不自动记为未完成。
- 与桌面排程算法对应的截止优先、碎片修复、每日负担平衡、课程交错；保护历史、已确认与进行中的任务；未排入量提示。
- 原子写入本地数据，保存失败保留原状态。备份导出和恢复通过系统文件选择器。

当前手机使用北京时间进行日程计算。不会发送系统通知；确认提醒仅在应用打开时出现。容量不足提示显示各课程未排入量，手机界面不展示桌面全部风险诊断细节。固定事项冲突通过修改时间或填写跳过日期解决。历史固定规则保存在数据中，在历史日期的日历可查看。

## 本机构建

已下载的工具位于 `tools/`，无需 Gradle 或 Android Studio；Java 11、Android SDK 35（aapt2、D8、zipalign、apksigner）进行编译和签名。

```sh
./Android/test.sh
./Android/build.sh
```

签名密码可通过 `STUDYPLANNER_KEYSTORE_PASSWORD` 环境变量提供；本机发布构建也可从 macOS 钥匙串的 `local.studyplanner.android.signing` / `release` 项读取。请勿将个人日程、设备备份、签名密钥或密码提交到仓库。`.gitignore` 已排除构建产物、工具目录、备份和签名材料。

## 验证

核心测试：50 组多课程场景，22,060 项断言，覆盖学习量守恒、时段不重叠、课程日期、固定课表避让、余量时间块、部分与未完成、重复确认拒绝、历史保护、固定规则拆分与冲突、归档、无可用时间及 1.2 默认时段 ID 迁移。

Android 15（API 35、ARM64）隔离模拟器已通过 34 项 SQLite/TLS/授权/增量同步设备检查、13 项两分钟窗口与资源释放检查，以及 Mac 客户端直连模拟器的完整二维码配对和双向同步。
