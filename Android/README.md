# 学习日程 · 安卓版

安装包：`../dist/学习日程-安卓版.apk`，适用于 Android 8.0（API 26）及以上，原生 Java 界面；使用局域网 INTERNET、扫码 CAMERA 和限时前台同步服务权限，无云服务器或存储权限要求。摄像头帧仅在内存中用于识别 Mac 配对二维码，不保存、不上传。

## 1.6.3 更新（2026-10-30）

新增浮动课程的具体预估起止时间、全局同步旋转提示，以及固定课表的本机文字识别；修复保存课表的风险核算和课程编辑删除课节时的进度保护。课程页的极限压缩方案只展示新版 Mac 经云同步传来的结果，不在手机计算，也不修改正式课表；手机输入变化后旧结果标为“待更新”。学习监督仅支持 Mac，Android 明确不加入，后续宽泛的功能对齐要求也不能覆盖此边界。范围与手机验收见 [功能对照](FEATURE_PARITY.md)。

## 安装与已有日程

把 APK 传到安卓手机，在文件管理器点开安装，按手机提示允许该来源安装应用。由于旧发布签名密码不可用，本次 1.3.0 已换用新签名：已安装 1.2 的手机必须先在旧版导出 JSON 备份，然后卸载旧版、安装 1.3.0 并恢复备份。

首次打开是空白日程，不包含课程、固定课表、任务、完成记录、备份或配对凭据。用户确认进度、修改数据、点击重排或跨天后会自动更新未来安排。

跨天刷新仅在数据库保存成功后记为完成；失败保留原日程，应用运行期间至少间隔5分钟重试，同一天连续失败只提示一次，避免反复弹出相同错误。

手机和电脑各自离线存储，通过热点可进行按需双向同步；详见 [同步使用与实现报告](../同步说明.md)。Android 1.3.0 使用 SQLite，并自动迁移旧 JSON 文件，旧文件保留为备份；首次配对改为扫描 Mac 生成的一次性二维码，不再复制配对串。应用设置中可导出与恢复 JSON 备份。未来使用当前新签名的覆盖安装会保留手机进度；卸载或清除数据会删除手机记录。内置快照仅在没有本地数据时载入，遇到损坏数据报错，不用空数据覆盖。

## 本轮安卓更新（2026-10-22）

- 底部新增「学习」入口：每日后果预报、昨日核对、排程负担、周统计、待确认任务、今日实际开课时间和重排集中在此。首页保留搜索、日历与当天课程/事项卡片；搜索显示实际完成结果和分钟数。
- 同步 macOS 的五档后果推演（不学、25%、50%、75%、全部），确认进度不会降低当天目标；课程或可学时段变更后重算。仅以已确认的有效学习触发达标提示，重开不重复庆祝；开启系统减少动画时使用静态达标状态。
- 预报最多推演90天，历史在手机私有目录独立保留14天，不参与局域网同步或日程备份；新安装需要从当天开始积累昨日对照。课程/进度已变更或旧记录日期不明时，明确提示待核对。
- 单项及批量确认可选择实际学习日期；补录昨天不会计入今天的目标。真实确认流水中的 `studyDate` 可与 Mac 同步，旧数据继续兼容。
- 排程优先守住截止日期，必要时放宽科目混排和倍率偏好，并用有界搜索联合调整整节课与浮动事项。警告区分负担偏重、排法待确认和已证实的时长/连续空档不足；未排入量不直接当作真实缺口。每日负担提醒线只保存在本机，不修改截止日或可学习时段。

## 功能

1.5.0 新增当天课程交换与顺序恢复、日程搜索、周统计、总学习负荷、截止风险详情、课程合并、智能课节排序与预览，以及网站和夸克网盘导入。完整对应关系、验证范围和手机验收步骤见 [Mac / Android 功能对照](FEATURE_PARITY.md)。

- 月历、当天时间轴、完成记录、课程进度。
- 课程管理支持名称、备注和截止日期组合搜索，兼容全角输入，可筛选「全部课程 / 自动排程 / 已暂停」或一键清除筛选；按截止日期排序，每页20门，当前页进度在后台计算。切换范围回到第一页，翻页和切换页面保留筛选条件，重新读取日程后更新进度；所有课程均可翻页查看，筛选不改变排程设置。
- 课节排序窗口支持名称组合搜索和50项分页，跨页及筛选外选择会保留，并显示全部已选数量；移动位置使用完整列表序号，可一键清空全部选择。移动和删除仍需保存才生效。
- 固定课表可切换「当前与未来 / 历史 / 全部」，搜索事项名称、备注和规则起止日期，每页20条；历史规则按结束日期从近到远列出，今天结束的规则仍归入当前。筛选和翻页不改动规则，旧规则可打开核对。
- 固定规则可以「复制为新事项」：保留名称、时间方式、时长、重复星期、备注与颜色，从日历所选日期开始（过去日期改为今天）；重复规则保留日期跨度，最远不超过今天起十年，单次规则仍为一天，旧跳过日期清空。仅打开独立草稿，保存时仍检查时间冲突，原规则不改动。
- 课程新增编辑、上课方式、总量与导入进度、起止日期、发布时间、优先级、颜色、备注、最小时间块、自动排程及删除（同时清除全部安排和完成记录，旧归档数据自动清理）。上课方式只有两种：「自主研习」只填总学习时长、按时间块分配；「分节研习」逐行填写课节名称与分钟数、按课节安排（如 `极限：60`，中英文冒号均可；格式或时长错误会指出原输入行号）；从 Mac 同步的网站课程按已抓取课节的剩余时长排程。
- 按节课程的课程卡片可点「调整课节顺序」，多选课节后移到最前、最后或指定序号，保存时从当前时间重排今天及以后的未确认任务；已结束和已确认记录保留。调整结果可与 Mac 同步，网站刷新时保留已有顺序。
- 单次与每周重复固定事项、起止日期、跳过日期、冲突检测、编辑和删除时保留历史及正在发生的事项。
- 固定事项支持「固定时间」与「时段内浮动」：指定窗口和连续占用分钟数，只预留实际时长。窗口内的学习任务在界面上标注为「时段内完成」，浮动窗口的占用时长累计计入容量；与桌面共用同一套浮动字段，旧数据继续按固定时间读取。
- 冲突详情按日期列出事项名称、起止时间、重叠时段和分钟数；浮动容量不足会解释原因；未确认的学习任务允许自动移动。每个日期可独立确认跳过，也可「全部跳过并保存」，同一天的多个冲突统一处理，只跳过当前编辑的事项。
- 多个每日可学习时段、休息日、全局时间块和应用内每日确认时间。
- 全部完成、部分完成、未完成、提前完成、逐项填写后批量确认；批量窗口每页最多20项，翻页保留未保存输入，保存所有页面已填写项。填写无效时跳到对应页面并指出项目编号；留空项不自动记为未完成。
- 与桌面排程算法对应的截止优先、碎片修复、每日负担平衡、课程交错；保护已结束和已确认记录，允许今天未确认的课程实时重排；未排入量提示。
- 原子写入本地数据，保存失败保留原状态。备份导出和恢复通过系统文件选择器，文件读写及校验在后台执行。新导出的文件采用 Mac 相同的 `format: 1` 备份封装，保留课程、课表、任务、完成记录和设置；仍可读取旧 Android 裸日程 JSON。旧版 Android 不识别新封装。单文件上限 64 MiB；恢复前展示备份和当前日程数量，若核对期间日程变化则拒绝覆盖。每次恢复前会先原子保存一份当前日程到手机私有目录，设置中的「恢复前的日程」可以找回；保存这份记录失败时拒绝覆盖日程。仅保留最近一次，不进入云同步或导出文件，卸载或清除数据也会删除。启用云同步时，恢复后的日程也会同步到其他设备。
- 保存每日学习时段时，替换当天已结束但未确认的旧课表，保留当天最新实际开课时间、已确认进度和往日记录；仅修改确认时间或重排相同时段不清除历史。「学习」页重新输入实际开课时间也会立即移除当天旧的未确认安排。

当前手机使用北京时间进行日程计算。不会发送系统通知；确认提醒仅在应用打开时出现。容量不足提示显示各课程未排入量及按截止日期汇总的需要量、可排容量和缺口；全局学习负荷还显示理论容量阈值和可停学天数。固定事项冲突改为「逐日处理时间冲突」窗口：按日期列出冲突事项、重叠时段与原因，每个日期独立勾选「确认跳过这一天」，可「保存已确认选择」或「全部跳过并保存」；未确认的冲突不会写入。历史固定规则保存在数据中，在历史日期的日历可查看。

## 本机构建

已下载的工具位于 `tools/`，无需 Gradle 或 Android Studio；Java 11、Android SDK 35（aapt2、D8、zipalign、apksigner）进行编译和签名。回归测试另需 Node.js；WebView 文档开始脚本通过 `lib/` 中 AndroidX WebKit 支持库注入。

```sh
./Android/test.sh
bash Android/check-api.sh       # 完整原生源码编译检查，Linux/macOS 均可，不需要签名
./Android/build.sh
```

`check-api.sh` 优先使用 `JAVA_HOME`，Linux 也可从 PATH 中的 `javac` 找到 JDK；缺少 SDK 时从 Google 下载固定版本 Android 35 平台并校验 SHA-256，只缓存到被 Git 忽略的 `Android/tools/api35/`。已有 SDK 可通过 `STUDYPLANNER_ANDROID_PLATFORM_JAR` 指定 `android.jar`。该检查已纳入 `Scripts/test-ci.sh`，会编译完整界面、同步和核心代码，防止仅在桌面 JSON-java 中存在的 API 混入 Android；不会生成 APK、读取签名密钥或修改系统安装。界面触摸、系统生命周期与签名安装仍需另行验收。

签名密码可通过 `STUDYPLANNER_KEYSTORE_PASSWORD` 环境变量提供；本机发布构建也可从 macOS 钥匙串的 `local.studyplanner.android.signing` / `release` 项读取。请勿将个人日程、设备备份、签名密钥或密码提交到仓库。`.gitignore` 已排除构建产物、工具目录、备份和签名材料。

# 可选私人云同步（1.6.0）

学习设置新增独立云同步，默认关闭。配置私人服务器的 HTTPS 根地址和服务访问码后，两端上传完整压缩账本，由服务器按每条操作的时间合并；最新与旧版合计保留十份。修改、打开、回到前台、运行时网络恢复触发同步，系统 JobScheduler 约每小时检查，可能因省电或强制停止延后。访问码使用 Android Keystore 加密保存，不进入课表、备份或安装包。原热点同步继续可用，游标与凭据独立。

Linux 包的构建、安装、十版历史下载和验证边界见 [服务端说明](../Server/README.md)。当前不需要服务器 IP、SSH 密钥或真实访问码；未配置时继续正常离线使用。

周学习统计分开展示当前课表的计划分钟和实际已学分钟。实学按确认任务时填写的学习日期统计，提前完成或补录不会误计到原排课日期；归档课程的历史记录仍计入。无法确定学习日期的旧记录保留原进度，并单独提示未归入统计的总量。

课程导入失败后会保留本机抓取临时文件，可在课程页选择“继续未完成导入”，先分页核对课程名称、课节数、学习量、抓取时间及新课程截止日期，再确认重试；截止日期过期时可在核对窗口重新选择，无需重新抓取，仅影响新课程，已有课程保留起止日期。只有数据库保存成功后才自动清理文件。核对窗口也可主动“删除这份结果”，需再次确认并校验文件没有变化，仅删除所选临时文件，不改动已保存的课程或进度。系统可能清理应用缓存，因此此入口不替代正式备份。
