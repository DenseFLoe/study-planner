# Mac / Android 功能对照 · 1.6.6

## 2026-11-11 安排条形图与未学课程分配

「学习 → 查看课程安排与每日负担」同步 Mac 的三页检查：课程安排按课程 ID 分别显示剩余、已安排、未安排和截止日；每日负担使用统一刻度的青绿/橙双色条与提醒线，可切换全部日期；「未学课程分配」显示去重后的已排/未排总量，以及日期、课程、课节、时长和当天课表入口。学习页也展示剩余时间条和最重一天的条形图。总容量与连续空档冲突使用双色条，课间休息冲突保留原因和事项入口。

补学时间来自今天确认后仍未完成的内容，扣除后来进度；同一课节反复确认不重复累计，已移除课节不产生虚假补学量。已排补学包含在当日课表中，无需额外加时。每日提醒线只改变提示，不改变截止日、可用时间或排程规则；学习监督与极限压缩的平台边界保持原约定。

自动验证包含重复/部分确认、后来进度、未排入与部分排入、移除课节、归档、跨日、普通时间块、同名课程、暂停课程、临界提醒线及明细/日总量一致性。另执行完整 Android 回归、真实 Android API 编译及签名 APK 内容检查；当前环境没有可用的 Android 设备或模拟器，手机布局和触摸尚待验收。

手机验收：覆盖安装新版 APK，进入「学习」检查双色时间条；在三个详情页分别查看课程入口、全部日期开关和补学明细；点击「查看当天课表」及「调整可学习时间」核对跳转。用测试课节连续两次确认未完成，补学总量应仍等于一次剩余量；完成部分后总量应减少，移除可学习时段后应显示未排入。窄屏和较大系统字体下核对文字换行、图例与滚动。

## 2026-11-07 智能助手

Android 顶部「智能助手」及「设置 → 智能助手」提供与 Mac 相同的业务能力：

- OpenAI 兼容 Chat Completions（包括 DeepSeek）与 Anthropic Messages，服务地址、模型和密钥由用户在手机配置；密钥只用于原生认证请求头，按接收地址在 Android Keystore 加密保存，关闭助手后清空密钥输入并要求主动重新载入。
- 同一份17项工具定义与提示规则：课程、课节、已存课表、学习进度、规则、容量及休息约束、具体时段重叠、基于已有事实的算术、事项列表，以及课程/事项新增编辑删除、重新排课和同日任务交换的修改预览。
- 本轮发送范围只确认一次，显示接收方、模型、隐私提示和精确初始请求；后续必要查询自动继续，课表变化丢弃旧结果并最多重查3次。凭证直接阻止，不可点击放行；新一轮重新确认。接口失败无自动重试，最多8次请求和24次工具调用。
- 修改方案只保留在本机，模型不接收完整前后快照。回答完成后逐页查看全部课程、事项、任务与学习记录差异，再点击「确认应用」写入；修改前自动备份，备份后及 SQLite 事务提交前再次核对有效期。两分钟、跨天、时区/课表变化或任务开始后旧方案失效。可撤销最近一次助手修改；后续已有业务修改则拒绝覆盖，仍可使用自动备份。
- 多段对话、搜索、单项/多选/搜索结果全选/全部删除；删除前核对数量与标题，失败恢复整批记录，删除最后一段后创建空白对话。本机记忆支持添加、编辑、启停与删除，默认不启用。历史和记忆不参与课表同步或日程备份。
- 回答使用原生段落、粗体、标题、列表、引用、代码块和横向表格；不打开模型链接、不加载图片。查询过程可展开，内部证据编号不显示。历史在后台串行读写，损坏原文件不覆盖；关闭、进入后台、切换对话或改变输入/配置/记忆会停止当前轮次，已发出的内容无法撤回。
- 首次加载兼容 Android 系统数据目录别名，路径防护仅检查应用私有目录内的聊天文件及子目录；加载失败可「重新读取聊天」，保留原文件。正常加载后各管理入口不依赖 API 密钥。`AssistantTests` 回归系统别名、内部链接和读取恢复；`AssistantStartupInstrumentation` 提供隔离原生页面的首次启用、新对话及关闭重开检查，尚待设备运行。

新增课程仅限自主研习；分节课程仍只编辑 Mac 已支持的名称、日期、优先级、倍率、最小块和自动排程等字段，不通过助手改课节总量。固定事项冲突拒绝写入，不自动跳过。学习监督仍仅支持 Mac；极限压缩仍只读 Mac 经成功云同步传来的结果。

自动验证：`Android/test.sh` 的 `AssistantTests` 使用合成日程、模拟传输和临时文件验证请求循环、只确认一次、工具白名单、实际学习日期、课节关联、所有修改工具、过期/并发/保存失败保护、撤销、历史删除与凭证拦截；`Android/check-api.sh` 编译全部真实 Android API 代码。`AssistantInstrumentation` 为隔离 SQLite 提供备份后及事务末尾的拒绝/回滚设备检查。APK 结构、共享工具定义、源码标识和空白初始数据由 `Scripts/test-android-assistant-package.py` 验证。模拟服务不代表真实模型推理、网页登录、Keystore 或手机触摸已验收。

手机验收：覆盖安装后打开助手，自行配置支持工具调用的模型及密钥，先查询今日安排和周进度，核对每轮只确认一次；尝试新增一门测试课程，逐页查看差异再确认应用，然后撤销。查询期间同步修改日程应自动重查；修改预览后再改日程应拒绝旧方案。检查关闭重开后的历史、单项与批量删除、记忆启停，以及关闭后主动载入密钥。真实接口测试由用户自行进行；本轮开发不读取 Mac 密钥、不使用真实 API。

## 2026-11-05 浮动事项搜索结论

- 保存、逐日核对、恢复已跳过事项及重新排程区分「已找到完整安排」「已证实无法排入」「排法待确认」。搜索达到20,000次尝试但没有完整安排时，只说明达到搜索上限、未证实容量不足，不再把它当成连续空档不足的证明。

## 2026-11-05 休息空间冲突诊断

- 「学习」概览、补回安排详情和每日后果推演可解释已证实的课间休息冲突。例如：两节各60分钟的课只有一个120分钟空档，学习量本身够放，但课间至少还需15分钟休息；未排入的60分钟不等于必须删除60分钟学习。
- 只统计课程开始日到截止日内的可学习空档，先扣固定事项及已保留历史占用；忽略浮动事项占用，给每个空档一次免内部休息机会。连这一偏乐观的条件也不满足时才报告冲突。短固定间隔、复杂浮动组合或搜索预算用尽仍可能只显示「当前方案还没排好」，不能据此断言学不完。
- 固定/浮动事项可以与课间休息共用同一段时间，不重复扣除；单节结束后不强制再留尾部休息。提示建议增加截止日前的时段，或调整固定事项以腾出有足够间隔的空档，再重新排程；不会自动修改学习量、进度或截止日期。
- 从已保存课表刷新时，只保留与真实未排入内容有关的诊断，不用未应用的新草稿替换现有课表。升级后的当日旧预测缓存会重新计算，保留原目标、基线和达标记录；既往日期的报告保持原样。

自动验证覆盖整节/普通时间块、固定与浮动事项、相邻/重叠时段、跨日间隔、开始日/截止日、暂停课程、历史休息、保存课表刷新、每日预测和旧缓存更新；另用独立小规模穷举核查休息证明不会拒绝可行方案。真实 API 编译与临时签名 APK 打包检查不代表手机界面、触摸或真机安装已验收。

手机验收：用合成课程设置同日两节60分钟、可学习08:00–10:00，查看休息原因和调整建议；延长到10:15后重新排程应排完。再加入09:00–09:15固定事项或同窗口15分钟浮动事项，应仍可排完；将固定间隔改为5分钟、末尾改到10:05，应保留「排法待确认」而非强行给出休息不足证明。核对课程总量、截止日和完成记录不变。

## 云同步连接方式（1.6.1 构建 16）

设置 → 云端同步提供「HTTPS 直连」「SSH 密钥」两张可选卡片，选择后点击保存才切换使用方式；地址、私钥与服务访问码分别保存，互不覆盖。

- HTTPS 直连：只接受可信证书的 HTTPS 根地址，不接受跳转，也不跳过证书校验。现有 HTTPS 部署与 systemd 文档继续有效，见 Server/README.md。
- SSH 密钥：填写服务器地址、SSH 端口（默认 22）、登录用户名、导入私钥（可填私钥口令）、SHA256 服务器指纹和服务访问码；连接后在服务器内部固定访问 `127.0.0.1:18090`。无需 Tailscale，不要求公网开放 18090 或有域名。
- 指纹：首次读取的服务器指纹需与服务器主人核对后保存；之后指纹变化必须停止连接、重新核对，不能自动接受新指纹。
- 访问码：SSH 仍需要服务访问码（按 `Authorization: Bearer <SERVICE_ACCESS_CODE>` 使用），它不是 SSH 私钥。
- 本机边界：私钥与私钥口令只保存在本机安全存储，不进入日程同步包、备份或安装包。
- 私钥文件在后台读取，最大64 KiB，要求有效 UTF-8；读取或格式检查失败时保留原已选密钥及已保存配置。导入成功后仍需点击保存才生效；文件读取边界与流关闭由合成内容测试覆盖，真实文件提供器待手机验收。
- 连接生命周期：只在同步时建立 SSH 连接，同步结束或失败后关闭；Mac 使用系统 OpenSSH，Android 使用内置 SSH 库。
- Android 保存云同步配置时，在后台完成安全存储和同步状态重置；保存与网络同步互斥，期间到来的自动同步在成功保存后继续。已有同步尚未结束时拒绝切换配置，失败时保留表单供核对重试。

验收边界：共享合并、跨语言 gzip 互读回归继续有效。Android 共用 SSH 核心在 JVM 上、Mac OpenSSH 在真实服务器上通过了 Ed25519 登录、指纹不匹配拒绝、内部 HTTP 无访问码状态探测及隧道关闭检查，没有读写真实日程。Android 真机的 Keystore、卡片界面、私钥口令与后台断线恢复仍待设备验收。

- 网页导入在独立进程和独立 WebView 数据目录中进行（API 28 及以上）；每次打开及关闭都清除登录 Cookie、网页存储与缓存。API 26 / 27 使用同一进程，并在普通导入期间暂停网站更新；普通导入仍清除会话。自动更新在 API 28 及以上使用独立于导入窗口的本机持久会话，避免互相清理。课程快照及网盘文件信息只保留白名单字段，分享凭据不会进入保存、同步或导入临时文件。

## 新包手机验收步骤

1. 用现有签名覆盖安装 `dist/学习日程-安卓版.apk`；设置页确认版本 1.6.3。已有记录应保留。不要通过卸载旧版来升级。
2. 选一天有至少两个未确认任务的日期，分别用拖放和“交换本日顺序”交换；重开、重排及与 Mac 同步后核对顺序和课间休息。
3. 搜索课时并跳转，核对周统计；合并两门测试课程，预览、排序、确认与撤销后核对剩余量。
4. 在导入窗口自行登录网站，核对课节、时长、进度并预览；重复抓取后应更新同一课程并保留本地完成流水。
5. 读取自己的夸克分享，分别检查提取码、子目录、多个分页、未知时长、目录批选及合并；关闭窗口重新进入应需要重新登录。
